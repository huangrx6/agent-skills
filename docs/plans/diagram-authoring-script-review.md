# diagram-authoring 脚本审查与交付规则修订

审查日期：2026-10-16。范围为技能内全部 Python/JavaScript：原有 32 个文件，加上本轮新增
`dev-tools/sync_exports.py` 后共 33 个。检查职责、入口、引用、外部依赖、落盘行为和错误处理，
针对发现的问题补充行为回归；这不是全部布局算法的数学正确性证明，也不是独立视觉评审。

## 本轮实施

1. 新图默认只生成可编辑文件及必要制作输入，不默认导出 PNG/SVG，也不以验收为由额外生成图片。
   交付时告知可按需导出；原生检查通过与真实渲染未验证分开说明。
2. 更新原生图后执行 `sync_exports.py`：刷新同名已有格式，显式 `--format` 才增加格式。
   没有导出时不调用渲染器，也不创建导出配置；首次需要图片时才保存必要参数。
3. 仅 SVG 请求不再顺带生成 PNG，浏览器里也跳过 PNG 导出 API。全部格式先在临时目录生成，
   成功后再替换；渲染失败保留旧文件，发布失败尝试回滚，源图/目标并发修改时停止覆盖。
4. 导出参数检查补充非有限倍率、负边距和无法容纳留白的画布；保留 80 单位默认外边距。
5. 拆图在落盘前检查是否覆盖源规格、计划或配色；配色对照图隔离跨面板分组 ID。
6. 历史基准的节点别名统一绑定，边端点找不到不能跳过；歧义或重复绑定不再当作有效匹配。
7. 修正文档中强制预览、错误 CLI 示例、过时 UMD/字体表述；删除未使用局部变量，关闭读取规格的文件句柄。

## 验证与边界

- 648 项回归中 647 通过、1 因可选真实图标库缺失跳过；26 个命令行 `--help` 入口检查通过。
  五份历史冻结候选经修订后的语义门复查均通过，原历史回执未改写。
- 回归覆盖：无导出时零副作用、SVG-only、现有格式并集、删除格式不复活、参数沿用、导出失败、
  发布失败回滚、源图/目标并发变化、双后端同名歧义、缺失输出、非法配置、输入覆盖与分组隔离。
- 用临时公开样例做官方浏览器实测：无请求不产生图片；显式 SVG 仅产生 SVG；
  修改原生标签后无 `--format` 只刷新 SVG；明确新增 PNG 时刷新两种格式。
  测试不修改业务项目，测试图片不属于默认交付。
  最终官方 SVG 检查通过，PNG 经作者目检；不是独立视觉评审。
- 同步工具默认识别同目录同名输出；自定义文件名/外部路径必须根据引用显式更新。
  Excalidraw 支持 PNG/SVG，draw.io 支持 PNG/SVG/PDF/JPG；不伪造其他格式。
- 未知旧导出参数无法可靠反推，首次接管应根据原命令/约定显式传参；无依据时披露采用默认值。
  高级 draw.io 导出选项仍由后端工具处理。发布是逐文件替换与普通异常回滚，不是抗进程崩溃的跨文件事务。
- 未拆分大型 layout/palette、未统一所有动态加载函数；这些修改会触及状态隔离和几何稳定性，
  与本轮导出诉求无直接收益，不能用“清理”为由扩大风险。未重新绘制公开历史样例。


## 后续补齐：draw.io 与 Mermaid（2026-10-16）

在上述 33 个脚本基础上增加 4 个，共 37 个；原有脚本不因新增后端而删除。

| 新脚本 | 职责与边界 |

已有脚本改动：draw.io 默认名义留白 80；多页图片要求页码、PDF 默认全页；
`sync_exports.py` 增加 Mermaid 与三后端同名歧义保护，保存 draw.io 页码，仍不自动生成新格式。
压缩文件回读不代表任意手工几何均可可靠估算；嵌套相对坐标明确停止估算，改为实际渲染审查。
Mermaid 仍不支持反向解析到 JSON，不接受几何预设，也不宣称全文档类型无损转换。
