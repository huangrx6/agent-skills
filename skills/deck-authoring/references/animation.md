# 逐页动画与视频

## 先让画面成立，再编排运动

灵动可以来自主体偏心、尺度变化、裁切、安静区与页间接续，先在静态完整画面中成立；
不能用大量入场动画掩盖同构版面。运动用于解释变化、引导阅读或形成与主题相关的记忆点。
在项目设计记录中说明用途即可，不为满足元素数或页数制造运动。

HTML 动效不以导出 MP4 为前提；“自读”“先 HTML”也不自动禁用。已要求的效果直接实现，
其余按观看方式与内容选择。纯静态方案可以成立；用户要求共同决定时再把运动纳入样张讨论。

从内容关系编排：章节切换可以停顿；过程按因果分组揭示；比较对象同步出现以免暗示先后；
数据与结论落定后留出阅读时间。范围、速度和强弱由选定设计决定，不把所有元素一律套相同淡入。
大段自读文字应很快达到完整可读状态；翻页由用户掌握，不能为了逐步解释持续挪动已开始阅读的正文。
一个主要运动已经建立阅读方向时，其余元素可以保持稳定；不要让每段文字、图片和背景同时竞争注意力。
默认阅读、减弱动画和静态导出应保全信息，持续效果另给可重现的导出状态。

自由 HTML 的播放器只执行作者编排的效果。没有 `data-reveal` 或自定义动画时，R 键、时间轴、
翻页操作不会替静态页面创造入场。PNG 是完成态，也无法证明运动存在。
在代表页实际试播正常打开、翻页、R 重播；检查起始/中途/落定、减弱动画和 `?scroll` 的完整状态。
自定义效果另按其实现验证，不能仅凭 CSS 声明或 reveal 数量报告成功。
配图待回填时可验证文字运动，但图片裁切、揭示和组合效果仍列为待验证。

`animate.py` 将 HTML deck 按既有时间轴捕获为 MP4 或 GIF。
它适合自动播放的逐页演示，不提供多镜头剪辑、配乐、字幕轨、3D 或 shader 效果库。

两条制作路线共用导出接口。本篇 motion token 与角色动画描述针对结构化 `render.py`；
自由 HTML 的 `fade/rise/wipe`、分组时间与减弱动画见 [web-composition.md](web-composition.md)。
动效可按内容与方向选择，不限于轻微入场或统一节奏。素材仍遵从项目要求，
例如用户禁止 SVG 时不能为做动画自行引入。自定义效果需要自行实现稳定阅读状态和确定性取帧，
不是 `animate.py` 已有的效果能力。

## 分开设计转场、讲解与静态结果

| 层次 | 设计决定 | 本 skill 当前能力 |
| --- | --- | --- |
| 整页切换 | 章节边界怎样提示、是否保留空间方向 | 自由 HTML 默认直接切页，没有内置 16 种转场菜单；复杂切换需要实际扩展播放器 |
| 页内讲解 | 哪些内容同步出现、哪些依次揭示，何时停止 | 自由 HTML 内置 `fade/rise/wipe`、`data-at`、`data-duration`，随页面入场播放；没有点击逐步揭示的现成接口 |
| 对象变化 | 位移、缩放、路径或状态怎样解释机制 | 可在项目中实现，但自定义动画不会自动接入播放器的播放、重播和 `seek(t)` |
| 静态交付 | 动作结束后应保留哪些信息 | PDF/PNG 展示可读的完成态；若前后状态互相覆盖，另排静态步骤或拆页，不能只截最后一帧丢掉前因 |

动效方案在已有设计记录中简记对象、用途、顺序/触发、时长与静态结果。例如分支图先显示共同输入，
再同时揭示两个分支，最后显示条件；比较矩阵同时展示共同维度，只强调当前讲解的差异。
这是编排示例，不要求每张图逐步出现；长解释不通过拉长动画来补救。

## 落定后层级不能变

入场动画有一个容易忽略的副作用：**它改的不是动画，而是图层**。`transform` / `translate` / `filter` /
`mix-blend-mode` / `opacity < 1` / `will-change` 都会让元素临时成为独立图层，播放时压住原先在它上面的元素；
动画结束这些属性消失，元素回到 DOM 顺序参与绘制——图文关系就在落定那一瞬间翻过来。
观众看到的是：字先清楚着，图一出来把字盖掉；或者文字从图下面冒出来，边缘糊成一片。
PDF / PNG / 贴图 PPTX 取的都是完成态，落定后的层序错，所有静帧导出都会跟着错。

规则：

- **参与叠压的元素各自定层。** 只要图文有重叠（哪怕只压住一角），文字和图都设 `position` + `z-index`，
  按背景 0 / 装饰 10 / 图 20 / 遮罩 25 / 文字 30；不要一个设层、另一个靠 DOM 顺序兜底。
  双方都有明确层号时，动画期间临时成层、落定去层，顺序都不会变。
- **reveal 只包原子元素。** 一段文字、一张图各自包一层；不要用同一个容器同时包住图和文字——
  容器一成层，里面所有东西的上下关系都跟着容器走，再和外面的图层抢顺序。
- **落定后不留层。** 自写的 CSS 动画结束时回到 `transform: none`、`opacity: 1`，不要常驻
  `will-change`、`filter` 或半透明。内置 `data-reveal` 落定时会把内联 `translate` / `clip-path` /
  `opacity` 还原成作者原值；自写效果要自己保证同样的落定状态。
- **看三帧，再对静态。** 入场前、入场中、落定各看一次，并和 `?scroll` 的完成态并看：
  文字有没有被图压住、图有没有被文字条盖住、有没有哪一层在落定时跳位。只看导出静帧发现不了。
- **遮挡是设计动作，要标出来。** 让图从文字后面穿出、文字咬住图的边缘，属于构图：主体不能被切，
  文字要落在安静区，并在元素上写 `data-web-check-allow="media-occluded text-occluded"` 和理由。

文字压在图上看不清时先别调 z-index：多半是图本身没有落点（主体占满画面、高细节铺到底）。
换图或换构图比调层更快。`web_check.py` 只在完成态采样，能报“文字被不透明前景盖住”和
“媒体被容器裁掉或被盖住”，但看不到播放中的临时层，也看不到“字压在高细节区读着脏”——
这两件事只能靠实际播放和目检。

需要 Anime.js 等引擎时，先把指定版本和依赖接入项目，再显式打通本播放器与自定义时间轴：
正常播放、R 重播、跳页取消、`seek(t)`、减弱动画与静态完成态要一致。自定义时间轴关闭独立自动播放，
由统一时钟驱动；仅复制 `<script>` 或写出效果名不能算完成。原理可参考
[Anime.js Timeline](https://animejs.com/documentation/timeline/)，它不是本 skill 已内置的依赖。

Oh My PPT 的 [整页转场配置](https://github.com/arcsin1/oh-my-ppt/blob/56bc56d41e6065bbb7fa21f2b3ea407575cb3aae/src/shared/index-transition.ts)
与 [元素动画协议](https://github.com/arcsin1/oh-my-ppt/blob/56bc56d41e6065bbb7fa21f2b3ea407575cb3aae/src/shared/element-animation.ts)
相互独立：后者用类型、方向、时长、延迟、交错、触发与分组编排整元素。
这些 `data-anim` 属性不能直接粘到本 skill 的 `data-reveal` 播放器。外部风格说明里的动画名也未必属于其可导出协议，
应核对运行时；其 [生成约束](https://github.com/arcsin1/oh-my-ppt/blob/56bc56d41e6065bbb7fa21f2b3ea407575cb3aae/src/main/agent-runtime/prompt/composers/shared.ts)
将可编辑路线限制在支持的整元素效果，不把 Anime.js 的全部能力等同于 PPTX 保真能力。

## 结构化路线的运行方式

| 场景 | 时钟与画面 |
| --- | --- |
| 默认滚动 HTML | 静态满态，供阅读、测量与 PDF |
| `?present` / P 键 | 实时时钟，当前页入场 |
| 动画取帧 | `window.__deck.seek(t)`，按确定时间点画同一套入场 |
| PNG 截图 | 取各页入场完成后的静帧 |

内部 paint 按语义角色编排：标题遮罩揭示并落定、条目小位移淡入、
图片横向揭示、分隔线延伸、图表容器淡入、页脚淡入。
当前 G2 图表内部动画关闭，**没有柱生长或折线逐段描画**；
不能因为运行时代码保留了图形动画钩子就宣称 G2 数据标记也会运动。

结构化运行时的入场属性由 `seek(t)` 直接赋值，不能再给这些属性叠加按墙钟推进的 CSS `transition`，
否则同一时间点可能得到尚未落定的画面。运行时用独立 `translate` / `scale` 保留皮肤的 `transform`；
皮肤若也需要控制这些独立属性，可分到其他包裹元素并实测取帧。这是当前实现的组合约束，不是动效风格限制。

没有单独的 motion_intent、energy、Effect Registry、motion creativity 或自动效果评分字段。
结构化路线通过 style.motion 控制速度与节奏；更复杂的效果可在自由 HTML 中实现并验证，
不要把自定义效果名当成现有 schema 参数。

## Motion tokens

`style.json` 的 motion 对象需要以下七项：

| 键 | 含义 |
| --- | --- |
| `easing` | `expoOut` 或 `overshoot` |
| `cssEase` | CSS 缓动字符串 |
| `enterMs` | 单元素入场时间 |
| `staggerMs` | 相邻正文元素延迟 |
| `titleHoldMs` | 标题领先正文的停顿 |
| `holdMs` | 每页基础阅读时间 |
| `readPerItemMs` | 按条目/节点等数量增加的阅读时间 |

时间单位为毫秒。选择节奏时结合观看方式、内容阅读与已选视觉表达，
不按主题类别预设动效强弱。同一套时间参数并不保证每页都好读，需抽帧与播放检查。
时间轴根据内容量追加阅读停顿，当前每页 hold 有上限；内容密度、阅读时间和节奏需一起判断，
需要超出当前能力的编排时明确实现方式。

## 导出

依赖见 [README](../README.md)：Chrome + websockets；MP4 另需 macOS 的 swiftc/AVFoundation，
GIF 使用 Pillow。依赖不具备时报告缺项，不声称已导出或自动换成另一种格式。

```sh
python3 scripts/animate.py deck.html -o deck.mp4
python3 scripts/animate.py deck.html -o deck.gif --width 960
python3 scripts/animate.py deck.html -o deck.mp4 --width 1920 --fps 24 --keep-frames
```

MP4 默认宽 1920、24fps，GIF 默认宽 960，按 16:9 输出。
`--scale` 控制浏览器取帧密度，默认按输出宽度决定；需要超采样可显式给 2。
`--keep-frames` 保留 PNG 序列，便于复查或外部编码。

只检查关键时间点时使用 `--stills`（逗号分隔秒数）；时间从 HTML 的
`window.__deck_timeline` 取得，覆盖页初、入场完成、切页前后与结尾。
`--slow` 是排查 CDP 的慢路径，每帧启动浏览器，不作为日常模式。

## 验收

捕获等待字体、图片解码、图表 ready。资源失败或 pending 不能当成完整视频；
切页后的图表实际绘图区也要保持尺寸，不能只检查容器或 canvas 存在。

先抽帧再编码长视频，确认开头不是上一页残影、正文完整落定、图表/图例未挤窄，
末页停留可读。完成后回读帧数、时长与尺寸，再实际播放检查切页和阅读节奏。
静态页面通过 check 并不能证明运动阶段没有遮挡或裁切。默认打开和静态导出应完整可读，
持续背景动效或互动效果可以保留，但需提供可重现的导出状态，避免元素意外跳位。
