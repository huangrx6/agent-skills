# 阶段闸门：制作是一条链路，上一关没过不进入下一关

一次 deck 制作有七个闸门。每一关都有**可核验的产物**，没有产物就不算过；
上一关没过就做下一关的事，返工成本比按顺序做高一个量级——这不是流程洁癖，
而是「图位还会变就交给用户出图」「样页还没确认就铺 28 页」这类错误的唯一拦法。

状态写在 `design.md` 的 `## 阶段闸门` 表里（不是新的状态 JSON），
用 `python3 scripts/gate_check.py` 核验：

```bash
python3 scripts/gate_check.py /path/to/v2-.../          # 当前在哪一关、下一关缺什么
python3 scripts/gate_check.py /path/to/v2-.../ --json checks/gates.json
```

## 七个闸门

| # | 闸门 | 入口条件 | 出口证据（缺一不算过） | 谁确认 |
| --- | --- | --- | --- | --- |
| **G1** | 范围与内容 | 知道讲给谁、讲多久、材料在哪 | `design.md` 写清观众与场景、事实来源、页数上限；每页一个问题（分镜表第一列） | 作者 |
| **G2** | 风格 | G1 通过 | 用户**看见过页面**（A 档案例或 B 档样张）；五个必答问题有答案；有反例；用户依据记进 `design.md` | **用户** |
| **G3** | 样页 | G2 通过 | 至少 3 张 hero 实际渲染截图（封面 / 最难讲的内容页 / signature）；两轮审稿记录；major 清零 | **用户** |
| **G4** | 配图交接 | G3 通过（图位不再改） | 图位实测尺寸；`image-plan.json`；`image-brief.md` 已交且逐图有提示词；用户知道要生成什么、放哪里 | 作者交接，用户接收 |
| **G5** | 全套 | G4 通过 | 全套页面写完；`rhythm_check` / `type_audit` 跑过；每 5–8 页编译一次无硬错误 | 作者 |
| **G6** | 审稿与回填 | G5 通过 | contact sheet + 逐页目标尺寸看过；图已回填且 `image_handoff.py --check` 通过（或用户明确确认不要图）；占位文字清零 | 作者 + **用户** |
| **G7** | 导出 | G6 通过，且用户选定格式 | 导出文件；PDF 用 `pdffonts` 回读、PPTX 回读页数与字体；交付说明写清仍缺的素材 | **用户** 选格式 |

## 越界清单：这些动作必须等

| 想做的事 | 必须等到 | 为什么不能提前 |
| --- | --- | --- |
| 铺完全套页面 | G3 通过 | 样页没过就铺开，等于把未确认的构图复制 28 次 |
| 写 `image-plan.json` / 交 `image-brief.md` | G3 通过（图位定稿） | 样页一改，图位比例就变，用户白出图 |
| 让用户开始生成配图 | G4 通过 | 提示词会随图位与文案一起改 |
| 跑 `pdf.py` / `pptx_native.py` | G7 | 图没回填、字体没核对的导出只能叫草稿 |
| 用检查器通过宣告「设计完成」 | 永不 | 检查器只覆盖几何与可测量项，审美仍是判断 |
| 把参考截图放进 `assets/images/` | 永不 | 那是「作者看过什么」，不是「本 deck 画了什么」 |
| 顺手改上一版目录 | 永不 | 上一版是验收对象，只读 |

**「顺便把后面做了」不算进度。** 已经越界时：不要在原闸门上打补丁，
回到对应闸门重做这一步，并在 `design.md` 记一句「回到 G3：原因」。

## 检查器只服务当前闸门

- G3 之前：`web_check` 只用来发现容量与越界，不是设计验收。
- G5：`rhythm_check` / `type_audit` 用来发现结构与字族问题。
- G6：`image_handoff --check` 验图；`design_signals` 是审稿提醒。
- G7：导出后回读。

检查器报错**只在本闸门内修**。拿「先把检查过掉」当进展，是本文档要拦的第二类错误。

## 每关结束要报一次状态卡

不要求长，但四项齐：

```text
当前：G3 样页（已出 3 页，等你确认画风）
依据：preview/hero-v3/page-01..03 · design.md 审稿记录两轮
下一关：G4 配图交接——确认后我量图位、写 image-plan 与 image-brief（约 14 张）
需要你：看一眼有没有「这不是我要的感觉」，有就现在说
```

## 被否掉时

- 否的是**风格**（G2/G3）：删掉本版页面的视觉决定，回到 G2 重新取证据；
  不在原方案上换配色、换字体继续。
- 否的是**局部页**：只重做该页与该页的图位，闸门停在 G3，不退回 G1。
- 否的是**内容范围**（G1）：回到 G1 重排页序，已有的样页按新问题重推，不继承旧骨架。

## 这份记录不替代判断

闸门保证的是**顺序与证据**，不保证好看。G3 通过只说明三张样页立住了；
整套是否成一个世界，仍按 [审美闸门](design-review.md) 与 [视觉审稿](visual-quality.md) 看。
