# 从主题推导构图

本篇处理画面中的主次、空间与阅读关系。制作如何推进见 [项目设计记录](refined-workflow.md)，
排印实测见 [排印与空间](typography-and-space.md)，成稿判断见 [视觉审稿](visual-quality.md)。

## 让视觉语言属于这份材料

结合当前材料与已确定的视觉方向组织画面。内容里的对象、动作、尺度或证据可成为视觉主角，
也可以由品牌语言、字形与抽象构图建立气质；不要求把每个主题字面图解化。

参考作品时观察具体做法：焦点怎样建立，文字怎样与图像相让，空白在哪，颜色承担什么作用。
风格还包含可辨认的形象与处理方式；需要从参考提取它们时，读 [视觉语言](visual-language.md)。
借用这些关系，用本项目的内容重新设计。品牌和系列作品可以跨主题复用视觉语言，
各页信息仍按实际材料组织。用户明确选择优先，不预设字族、色系或效果黑名单。

例如解释链路时，可以沿着同一对象逐页查看状态；每页保留方位，只放大本次要解释的段落。
技术名放在作用位置，部署并列与执行先后分别表达。介绍工艺时可以让材料细节建立感受，
由真实步骤承担事实；概念图不能代替实拍证据。视觉主张应能发展为内容页，不只是封面的装饰。

## 先决定主焦点、安静区与阅读路径

用本页真实材料安排这三者，无需创建额外字段：

- **主焦点**：观众第一眼应看见哪个判断、对象或证据？让它在面积、位置、明暗或字形上具有主导性，
  其余内容帮助解释它。主角可以是图或数字，标题不必每页都是最大元素。
- **安静区**：哪一片空间要让焦点独立、让视线停顿或分开信息？保护它，不用小标签、纹理或装饰补满。
  安静区可以在侧边、主体周围或组间；不是默认页底剩余的一块空地。
- **阅读路径**：观众从主角到解释，再到条件和来源怎样移动？比较需要共同尺度，过程需要方向与分支，
  证据靠近它支持的判断，整体与局部保持可辨的方位。空间不能暗示不存在的时间、因果或依赖。

标题位置是构图的一部分。它可以靠近被解释的图、位于侧栏、下方或空白的一端，也可以保持传统页头。
先看什么、再看什么清楚即可，不必每页都保留同一条“上方标题＋下方正文”横带。
需要解释的长标题按语义换行；用紧邻的次级说明容纳条件，不能靠删限定制造短标题。

## 让不同方案改变组织方式

方向未定或已有页面同构时，选同一段代表内容尝试不同的主角、尺度、标题位置、证据展开或阅读路径。
例如完整截图旁列说明，与放大关键区域并将解释贴近对应位置，是两种不同组织；
同一组等宽栏换颜色、去底框，仍然保留原来相同的视觉重量。

比较时保留相同事实，使用真实字形与素材比例。线框可用于快速探索，但不能代替实际渲染。
选择能保全信息且视线更顺的方向，再发展细节；已有构图成立时，无需为流程制造替代稿。

## 用尺度与空间形成张力

统一的对齐骨架可以支持不等宽的内容、偏心的主体、局部放大的证据和受控的裁切。
先看大形与重量是否平衡，再看每个元素是否整齐。非对称需要可辨的关系，随机错位不会带来灵动。
大小差别也无需层层等差：关键图像可以很大，旁注保持小而清楚，中间不必塞入一组竞争的小标题。

将空间容器、可见表面和内容分开：Grid/Flex 负责定位，表面表达分组或边界，内容按阅读需要取高。
框可以保留，但不能因为有小标题就自动分成相同卡片；去掉框后仍需重审列宽、尺度与路径。
不要用放大所有字、扩大空盒子或统一垂直居中来填空间。

留白不能靠丢失证据获得。先重组解释、缩短重复表达，必要时拆成有接续的页面；
影响结论的条件留在相关判断附近，其他细节可进后续页、讲稿或附录，并保留来源去向。
若空间显得单薄，检查主体是否太小、材料是否还未展开，或项目的视觉想法是否没有落实。
有主题依据的图形、纹理和装饰可以建立气质与节奏；它们不必各自解释一条数据。关键是与构图一起设计，
而不是在排完文字后向空处撒图标，也不为了“克制”把有辨识度的表达全部删掉。

## 页面利用率：内容带要有意

内容不要默认顶在上半页。先定义一个**内容带**：标题、主体、收束在画面中的上下位置。
内容带通常占可用高度的 60–80%；低于 55% 时，先问是主体太小、材料没展开，还是内容带没排：
放大字号、图或数字，或让一个视觉锚点占住下半部；也可以有意居中，让上下留白对称。
最差的是“顶部 60% 挤满 + 底部 40% 空着”，再加一条贯穿全页的装饰竖线，把空放大。

- **卡片并排时先算内部空间**：1600 宽三列，每列可用约 440–480px；正文从 22–26px、行高 1.5–1.7、
  内边距 28–32px 起。放不下就减列、拆页或删字，不缩字、不压行距。
- **间距要有层级**：内边距 < 组间距 < 页边距通常成立；三者比例失当时，页面会显得“框很大、字很挤”。
- **全高装饰要和内容带同步**：竖线、边栏、刻度拉到全高、内容却只占上半，只会强调空。
- **空间单薄先查主体**：主体是否太小、材料是否还没展开、视觉想法是否没落实；再考虑放大，
  不要用空白、拉高容器或统一垂直居中糊过去。

判断方法：把页面缩小到缩略图大小，看内容带是否像被“放在画面里”，而不是“堆在顶部”。

## 把整套当作连续表达

字体、色彩角色、对齐和图像处理形成连续性；主角、密度与位置按讲解任务变化。
看相邻内容页的轮廓：是否一直是相同标题带、等宽列和同样大小的图？若任务不同，重新分配视觉重量。
连续步骤、同维度比较或案例对照可以重复结构，帮助观众发现变化；不为变化而破坏可比性。

正常流、Grid/Flex 与测量机制可以复用，`assets/layout-starter.html` 不规定成品构图。
新内容的列宽、图像比例和间距需要重新验证；用户明确要求沿用版式时保留指定关系。
HTML 文件与相对资源路径契约见 [自由 HTML](web-composition.md)。
