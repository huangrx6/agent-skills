# 审美闸门：先看、再改、再看

几何检查发现资源、边界和部分遮挡；[视觉审稿](visual-quality.md) 提供观察方法；
本篇定义**完整新稿什么时候可以扩展全套、什么时候算完成**。它不评分，也不规定风格，
只要求三件事：可定位的问题、可见的修改、真实的回看证据。

> 审美不是检查通过，也不是“更精致”三个字。它是这一页有没有清楚的焦点、
> 站得住的尺度、可读的排印、整合过的图像，以及整套有没有自己的语气。

## 封面与尾页：独立设计，不塞内容

封面和尾页是这套 deck 的**语气**，不是内容页，也**不沿用内页的版式骨架**：
它们各只回答一件事，其余留白。内页那套「标题 + 引导 + 主体 + 脚注」的填法不要搬过来。

### 封面：只放元信息 + 一个立住气质的视觉动作

信息只留三样，其余全部删掉：

- **文档名称**——主标题，是这份材料的名字，不是本章论点
- **作者 / 团队**
- **时间**——日期或版本

最多再加一行 12–20 字的副题说明这是什么材料；**不写第二条解释，不写摘要**。

视觉上要让人第一眼感到这套东西的**态度**：超大字号、整块材质、一张压满的图、一个数字、一块出血色域——
任选其一做到位，并且敢留白。"只放三样字 + 一大片空"本身就是合格设计。
需要氛围时按 [配图](images.md) 规划 `cover` 条目（主视觉、材质或场景），不要用正文的证据图充数。

**禁止出现在封面**：目录、章节列表、流程预览、刻度尺、进度条、要点摘要、二维码、第二张图，
以及页脚式的技术元数据（`HEAD c242469` 这类留在内页脚注）。

### 尾页：一句收束，不是第三个知识点

最多一行主张（与封面呼应，但不是同一句），可选一个动作：一行去处、一个联系方式、一个"现在开始"。
**不要多栏并列**，也不要把"接下来可以看 / 值得核对 / 仍在改进"这类清单做成三块——那就是把尾页做成了信息页。
简单、大气：一句话 + 大量留白，比塞满更有分量。

### 两条都要求

- 用本 deck 的 **signature move**（重复 2–5 次的视觉动作），不能是通用模板标题。
- **需要图就明说**：封面/尾页的图片在 `image-plan.json` 里单列成条目（`role` 写 `cover` 或 `finale`），
  写清它承担什么（氛围、材质、主体）；不要把它混在正文图里，也不要"到时候再找"。
- 没有图时由版式承担：大字、出血、色块、留白，但必须有设计动作，不能只是"标题 + 副标题"。

### 验收

并排看封面和尾页：

1. 能不能认出这是同一套 deck 的头和尾？
2. 封面除了名称 / 作者 / 时间（+ 一行副题）还有没有多余元素？有就删。
3. 尾页是不是只有一句话？出现多栏、多块、清单就是超标。
4. 遮住封面文字，剩下的视觉是否已经传达了态度？

## 版面节奏：按「视觉主角」换页，不是按注解数量换页

页面同质化不是"字号都一样"，而是**每一页的主角都一样**：一页又一页的「标题 + 图解 + 一段说明」，
只是把图解换成表格、把说明换成结论——翻页时读者会觉得"又是这一页"。

**视觉主角**＝这一页第一眼落在什么上面：全幅图、出血材质、大数字、引文、表格、图解、剖面、
标注截图、拼贴、纯排版海报、留白停顿页。一套 deck 里至少出现 **4 种**不同主角。
标题、导语、注解、结论都是附属层，**不构成主角差异**——「图解 + 三块注解」和「图解 + 一句结论」
在视觉上是同一页型。

硬规则：

- **非图像主角不超过全书的 45%**；图像页不设上限，但整幅、框景、网格、拼贴要轮换，成排出现时逐页看构图。
- **不要连续三页用同一主角**；相邻两页同构只在信息比较时允许，也不要 A/B/A/B 交替——那只是两种模板轮换，仍然机械。
- 每 5–8 页必须出现一页**强主角**：整幅出血图、整页大字、一张大表、一段引文、一个数字。
- 不允许连续三页都是「标题 + 正文/图解 + 说明」；要连讲时至少换分栏、换主角，或插入一页停顿。
- 底部收束至少三种：三块注解 / 一句判断 / 一条引文或数字 / 什么都不放（但要靠图或留白撑住）。
- 不规则要克制而准确：非对称用 7/5、8/4、9/3 这类**可命名的比例**，断裂处必须共享一条对齐轴或基线。

检查：

```bash
python3 scripts/rhythm_check.py source.html
```

它按**视觉主角**给每页签名（附属说明只记有无、不记数量），报出占比过半、连续同构和主角种类数。
它只看结构，不判断美丑；结构过了仍然要逐页看截图。


在写第一页之前，把下面几项写进项目的 `design.md`（可从
[design-record.md](../assets/design-record.md) 复制）。不需要长，几行就够；
但**没有这些决定就开始铺页面，通常会回到默认模板**。

- **一句话**：这套 deck 想让人记住哪一个视觉关系？（不是“现代简约”，而是一个具体的画面判断。）
- **观众与场景**：现场投影、桌面自读还是打印；最近的观看距离。
- **参考拆解**：从实际参考里取出的 2–3 个具体 move，分别属于结构、排印、色彩/图像、空间。
- **项目决定**：视觉主导方式与母题、承担全部文本的字族与字号关系（第二族只在授权时出现）、颜色角色、网格与边距、图像处理、材质。
- **一个 signature move**：整套重复 2–5 次、但不每页出现的识别动作。
- **反目标**：这次明确不要什么（例如不要卡片阵列、不要紫色渐变、不要每页页脚）。

“高级、精致、技术感”不是命题；把它们翻译成可见的尺度、材质、构图或图像关系。
参考网站上的主题名也不是命题；没有实际作品或截图时，先取得可见依据。

## 三张 hero pages

完整新稿先做三张代表页，而不是先铺十页同构内容。
三张是最小集，不是三套主题；内容需要时可以增加，但不能只交一张封面：

1. **封面 / 开场**：主题气质、尺度关系和第一眼焦点。
2. **最难讲的内容页**：真实长标题、最长段落、真实数据或已接好的图位。
3. **signature page**：最想让人记住的一页。可以是全出血图、排印海报、
   单数字数据故事、图作为主角、索引/contact sheet，或一个材质封面。

要求：

- 用**实际标题、正文、数字和图注**，不用 Lorem、假标题或占位图证明审美。
- 在**目标观看尺寸**看（现场投影就按现场距离；桌面自读按普通窗口），
  不拿 4K 放大后的清楚程度判断。
- 三张**连续看**：标题位置、图文比例、密度和阅读路径是否有跨页亲缘，
  还是三张互不相关的样张。
- 图位未回填时只评结构与排印；图回填后必须重看主体、裁切和叠层，
  不能据占位图宣布图文关系完成。

## 八个轴

每次审稿按这八轴看，不要从圆角、阴影和局部间距开始。

| 轴 | 好是什么样 | 常见 AI tell | 可执行的杠杆 |
| --- | --- | --- | --- |
| **焦点与层级** | 第一眼就是本页要说明的对象、判断或证据；第二眼找到解释与条件 | 标题、三个小标题和底部总结同权；每块都像重点 | 先删/合并重复强调，再放大真正的主角；其余降一档，不要全部加粗 |
| **尺度对比** | 展示、标题、正文、辅助有明显跳级；主角可以是图或数字 | 标题 40px、正文 24px，整页像文档；所有元素差 2–4px | 标题提到正文的 2.4–3.5×，或让一个数字/图占据画面；先只改一层 |
| **网格与对齐** | 2–4 条共同轴支撑阅读；偏心有一致的边或基线 | 元素四处漂浮；“非对称”只是随意错位；每条边都对齐 | 找回左缘/右缘/图注基线；保留一次有理由的断裂，其余回到轴 |
| **留白与节奏** | 内容带占 60–80% 且上下有意；组间明显大于组内；内边距 < 组间距 < 页边距 | 底部空 300px、内容挤在上半；三列卡片字 14–16px 塞满；所有间距都是 24px | 先定内容带：放大字号/主体或加视觉锚点，也可有意居中；内边距 ≥1.2× 行高；放不下就减列、拆页 |
| **色彩** | 一个中性主族 + 一个强调色 + 必要的信号色；强调有面积预算 | 5–7 个高饱和色；紫蓝渐变；每个标题换颜色 | 按角色收色，不按页面收色；用灰度看一次，检查强调是否还成立 |
| **图像** | 图承担解释、证据或气氛；同一母题在封面、章节与内容页之间可辨认地重复；裁切保留关键内容；图注靠近证据 | 图只是等尺寸卡片；图很漂亮但换主题也成立；**插画被容器裁掉一角或被卡片盖住**；**同一角色既有生成位图版又有 SVG 版，或背景图已含角色、前景又叠一个**；整套缩小后只剩文字块与右侧小图；**本该画成关系图的段落仍是大段文字** | 先定形象媒介（位图或矢量，一套只一种）与母题出现方式（封面/章节/内容/数据），再定裁切、出血、叠层；换一张同主题的图，页面是否还成立；把段落改写成“谁→对谁→什么关系”，画得出来就别用文字 |
| **排印** | 断行自然、字重有分工、行长可读；中英混排基线协调 | 中文套负字距；长解释仍用标题字号；辅助字抢正文 | 中文从 `letter-spacing: 0` 开始；缩辅助、放正文，不靠全局缩字 |
| **跨页亲缘与变化** | 共享字体、色角色、图处理和阅读坐标；各页主角/密度不同 | 每页同一骨架，只换背景色；或每页换一种风格 | 先保共同坐标，再改变主角、尺度、位置和信息展开；同构只留给比较 |

一张页面不必八轴全优；但**不能有 blocker 级问题**，且不能三张 hero pages
都落在同一种安全构图上。

## 严重度，不是分数

| 级别 | 判据 | 处理 |
| --- | --- | --- |
| **blocker** | 内容/证据缺失、错、读不到；正文被遮挡；关键条件被裁掉 | 立即修；不进入全套 |
| **major** | 第一眼不是本页焦点；层级平；图只是装饰；形象混媒介；占位文字压图；动画落定后图文层序翻转；连续页同构且无比较理由；排印不可读 | hero pages 清零后再扩展；全套中要逐项处理或明确记录取舍 |
| **minor** | 局部间距、标点、单页细节、可再优化的质感 | 可在全套阶段处理；不阻塞 |

不设 1–10 分，也不把“通过/不通过”写成审美结论。
**major 清零**是扩展条件；minor 可以带着走，但要在记录里保留。

## 两轮，怎么算一轮

完整新稿的 hero pages 至少回看两轮。轮次不是目标，**证据**才是：

1. **第一轮**：看三张实际渲染，列出 3–5 个最明显的问题；只改最影响结果的
   1–3 项（通常是焦点、尺度、构图），重新渲染。
2. **第二轮**：把 before/after 并看，检查修改是否解决了原问题、是否引入新问题；
   再决定扩展或继续修。
3. 全套完成后再做一次 **contact sheet + 逐页目标尺寸**复核，修共享 CSS 后回看受影响页。

如果第一轮已经没有 major，也要在扩展前复看一次（可结合全套 contact sheet），
不能以“检查通过”代替；如果两轮后仍有 major，继续修，不靠增加轮次数量或换背景色凑数。

一轮不是：重跑检查器、改一个 CSS 值、生成截图但没看、写“已优化”。
一轮必须留下：**页/版本、看到的问题、改了什么、回看结果**。

## 证据

- 1600×900 的页面截图，以及目标观看尺寸的截图；现场投影另看实际距离。
- 全套 contact sheet（缩略图）用于看轮廓、密度和重复。
- hero pages 的 before/after；只贴 after 不能证明改进了什么。
- 交付格式的实际回读：PDF/PPTX 的字体、图片、图表和页数。
- 含动效时实际播放，看到入场前、中、完成态；静帧不能证明运动。

“我看了”不是证据；**指出哪一页的哪一个关系，改前是什么、改后是什么**才是。

## 全套复核

1. **contact sheet**：封面之后，标题是否总在同一高度？内容是否总是一排等重栏？
   图片是否总占同样大小？连续页是否只是同一骨架换字？
   把缩略图缩小到看不清字：是否仍认得出同一个视觉世界（母题、图像处理、节奏）？
2. **逐页目标尺寸**：用 [视觉审稿](visual-quality.md) 的观察表，看第一眼、路径、
   空间、排印、素材、风格落地和语义完整性。
3. **设计信号**：运行 `scripts/design_signals.py` 读取字号/字体/颜色/对齐/留白/
   图像/行长/卡片等可观测信号。它是提醒，不是分数；逐条判断是否成立，
   不要为了让信号消失而机械改值。
4. **字族**：运行 `scripts/type_audit.py`。它按选择器判断字族用途，代码语境与图标之外
   出现第二个文本字族就失败；第二族只有用户或品牌授权才用 `--allow` 放行。
5. **最终格式**：打开 PDF/PPTX 回读；HTML 正确不等于导出正确。

## 什么不算完成

- 几何检查通过、没有溢出、没有重叠。
- 只看了封面，或只看了高分辨率局部。
- 生成了全部截图但没有逐页看。
- 只写“更精致”“更高级”“符合参考”，没有可定位的页与关系。
- 只改颜色、圆角、阴影或动画，没有动焦点、尺度和构图。
- 图位仍是占位图，或图片内容/裁切未核对。
- 同一角色或物件有两种实现（生成位图 + 手写 SVG），或同一页叠了两套角色。
- 图上仍压着“待配图 / 文件名 / 尺寸”等占位文字，或文字压住图的主体。
- 图被容器裁掉一角、被卡片盖住，或 SVG 被压扁/拉伸出安全区，且没有标记为有意。
- 图按模型默认比例生成，靠 `cover` 裁切塞进功能图位，裁掉了标签、条件或坐标轴。
- 只看完成态截图：入场中与落定后的图文层序没有对过，动画一结束文字就被图压住。
- 内容只占上半页、底部空 40% 且没有视觉锚点；或卡片里靠 14–16px 正文塞字。
- 导出的 PDF/PPTX 未回读。
- 用 `design_signals.py` 的报告代替目检；信号清零不等于好看。

```md
## 2026-01-01 · hero v2

- 页/版本：p1 封面 v2；p4 机制页 v3；p7 signature v2
- 第一眼：p4 先看到右侧截图，但本页要讲的是左侧三个阶段
- 问题：阶段标题与说明同权；截图裁掉了底部条件；p1 标题与副题差 1.4×
- 改动：阶段标题提到 56px、说明降为 26px；截图改 contain 并补条件图注；封面标题 112px
- 回看：p4 第一眼回到阶段标题，条件可读；p1 尺度成立，但副题仍偏长，下一轮处理
- 仍未解决：p7 的图注与页码争抢底部；等图回填后复看
```

## 与现有文档的关系

- [视觉审稿](visual-quality.md)：怎么看、先修什么、哪些不能算。
- 本篇：什么时候算过闸门、要留下什么证据。
- [视觉 craft](visual-craft.md)：尺度、网格、色彩、图像、材质和反 slop 的具体杠杆。
- `scripts/design_signals.py`：把“像文档/像模板”的可观测信号列出来，供审稿参考。

## 系统层自检：八轴看不到的整套问题

八轴看的是单页。整套还有七件事，只有把 20 页以上放在一起才看得出来；扩展全套后、导出前各做一次。

| 检查 | 判据 | 常见错法 |
| --- | --- | --- |
| **强调色语义是否单一** | 列出强调色出现在哪几页、每处表示什么；只有一种含义才算成立 | 红色同时当"故障""编号""标签边框""分栏线"，读者不再相信它 |
| **表格是否共享列轴** | 3 张以上表时，第一列宽度、列数、表头基线应当复用同一套模板 | 每页各定一套列宽，翻页时列从不相遇，像拼起来的文档 |
| **收束元件是否过量** | 同一收束句或同一条"判断带"≤3 页，且至少换一次形式 | 每页结尾都来一句"一句话：…"，读者会跳过 |
| **字号档位总数** | 全套通常 ≤7 档；相邻两档差 <8% 时视为同一档，应合并或拉开 | 判断句 62px 与页标题 58px 并存，既不像同级也不像高一级 |
| **文字是否全部走项目字体栈** | 每段文字的字体栈里至少含一个已加载字族；边注、页码、单位最容易漏 | 字体只设在内容容器上，容器外的竖排边注落到系统字，PDF 还会嵌入系统字体 |
| **视觉母题是否贯穿** | 封面、章节/议程、内容页都能指认同一母题，至少三种角色、3–6 次 | 母题只出现在封面；每页一张互不相关的图；换掉图后整套仍然成立 |
| **图像是否参与结构** | 图像能承担解释或气氛就多用，不设数量上限；缩略图缩小后仍认得出同一个世界 | 文字块 + 右侧小图；图只是等尺寸卡片；用统一滤镜掩盖素材不匹配 |

`design_signals.py` 已能测其中三项：`cjk-tracking`、`low-contrast`、`system-font-fallback`；
`repeated-silhouette` 与 `equal-card-grid` 用来发现骨架重复和等权卡片。信号只提示位置，判断仍靠看页面。

## 节奏：长稿要有 register 变化

20 页以上如果每页都是"标题 + 内容 + 脚注"，单页都成立，连起来仍然是文档。扩全套前在记录里排一下 register：

| register | 长什么样 | 一整套里通常要几次 |
| --- | --- | --- |
| 内容页 | 标题 + 内容 + 脚注（默认） | 多数 |
| 停顿页 | 整页深底 / 全出血图 / 大号判断句，只讲一件事 | 3–5 |
| 证据页 | 一张图或一张表占主导，文字退到标注 | 2–4 |
| 过渡页 | 章节名 + 一句，或与上一页形成尺度断裂 | 章节数 − 1（可选） |

判断方法：把缩略图排开，看是否连续 6 页以上都是同一种轮廓；是就插入一次 register 变化，
不是把某一页换背景色。整页反转放在章节页或停顿页：**每章一次不嫌多**，它同时是母题的大尺度出现；
但不要连续两页反转，也不要让内容页都靠反色制造节奏——内容页里额外的反转停顿控制在 1–2 页。
