# 审美闸门：先看、再改、再看

几何检查发现资源、边界和部分遮挡；[视觉审稿](visual-quality.md) 提供观察方法；
本篇定义**完整新稿什么时候可以扩展全套、什么时候算完成**。它不评分，也不规定风格，
只要求三件事：可定位的问题、可见的修改、真实的回看证据。

> 审美不是检查通过，也不是“更精致”三个字。它是这一页有没有清楚的焦点、
> 站得住的尺度、可读的排印、整合过的图像，以及整套有没有自己的语气。

## 先写一句视觉命题

在写第一页之前，把下面几项写进项目的 `design.md`（可从
[design-record.md](../assets/design-record.md) 复制）。不需要长，几行就够；
但**没有这些决定就开始铺页面，通常会回到默认模板**。

- **一句话**：这套 deck 想让人记住哪一个视觉关系？（不是“现代简约”，而是一个具体的画面判断。）
- **观众与场景**：现场投影、桌面自读还是打印；最近的观看距离。
- **参考拆解**：从实际参考里取出的 2–3 个具体 move，分别属于结构、排印、色彩/图像、空间。
- **项目决定**：展示字与正文字、颜色角色、网格与边距、图像处理、材质。
- **一个 signature move**：整套重复 2–5 次、但不每页出现的识别动作。
- **反目标**：这次明确不要什么（例如不要卡片阵列、不要紫色渐变、不要每页页脚）。

“高级、精致、技术感”不是命题；把它们翻译成可见的尺度、材质、构图或图像关系。
参考网站上的主题名也不是命题；没有实际作品或截图时，先取得可见依据。

## 三张 hero pages

完整新稿先做三张代表页，而不是先铺十页同构内容。
三张是最小集，不是三套主题；内容需要时可以增加，但不能只交一张封面：

1. **封面 / 开场**：主题气质、尺度关系和第一眼焦点。
2. **最难讲的内容页**：真实长标题、最长段落、真实数据或已接好的图位。
3. **signature page**：最想让人记住的一页。可以是全出血图、排印海报、
   单数字数据故事、图作为主角、索引/contact sheet，或一个材质封面。

要求：

- 用**实际标题、正文、数字和图注**，不用 Lorem、假标题或占位图证明审美。
- 在**目标观看尺寸**看（现场投影就按现场距离；桌面自读按普通窗口），
  不拿 4K 放大后的清楚程度判断。
- 三张**连续看**：标题位置、图文比例、密度和阅读路径是否有跨页亲缘，
  还是三张互不相关的样张。
- 图位未回填时只评结构与排印；图回填后必须重看主体、裁切和叠层，
  不能据占位图宣布图文关系完成。

## 八个轴

每次审稿按这八轴看，不要从圆角、阴影和局部间距开始。

| 轴 | 好是什么样 | 常见 AI tell | 可执行的杠杆 |
| --- | --- | --- | --- |
| **焦点与层级** | 第一眼就是本页要说明的对象、判断或证据；第二眼找到解释与条件 | 标题、三个小标题和底部总结同权；每块都像重点 | 先删/合并重复强调，再放大真正的主角；其余降一档，不要全部加粗 |
| **尺度对比** | 展示、标题、正文、辅助有明显跳级；主角可以是图或数字 | 标题 40px、正文 24px，整页像文档；所有元素差 2–4px | 标题提到正文的 2.4–3.5×，或让一个数字/图占据画面；先只改一层 |
| **网格与对齐** | 2–4 条共同轴支撑阅读；偏心有一致的边或基线 | 元素四处漂浮；“非对称”只是随意错位；每条边都对齐 | 找回左缘/右缘/图注基线；保留一次有理由的断裂，其余回到轴 |
| **留白与节奏** | 组间明显大于组内；安静区服务焦点；连续页有疏密变化 | 底部空 300px、内容挤在上半；或所有间距都是 24px | 先建立同组/跨组/章节三种间距；把空间放到焦点周围和组间 |
| **色彩** | 一个中性主族 + 一个强调色 + 必要的信号色；强调有面积预算 | 5–7 个高饱和色；紫蓝渐变；每个标题换颜色 | 按角色收色，不按页面收色；用灰度看一次，检查强调是否还成立 |
| **图像** | 图承担解释、证据或气氛；裁切保留关键内容；图注靠近证据 | 图只是等尺寸卡片；图很漂亮但换主题也成立；图+黑蒙版+白字 | 先定图的角色，再定裁切/出血/叠层；换一张同主题的图，页面是否还成立 |
| **排印** | 断行自然、字重有分工、行长可读；中英混排基线协调 | 中文套负字距；长解释仍用标题字号；辅助字抢正文 | 中文从 `letter-spacing: 0` 开始；缩辅助、放正文，不靠全局缩字 |
| **跨页亲缘与变化** | 共享字体、色角色、图处理和阅读坐标；各页主角/密度不同 | 每页同一骨架，只换背景色；或每页换一种风格 | 先保共同坐标，再改变主角、尺度、位置和信息展开；同构只留给比较 |

一张页面不必八轴全优；但**不能有 blocker 级问题**，且不能三张 hero pages
都落在同一种安全构图上。

## 严重度，不是分数

| 级别 | 判据 | 处理 |
| --- | --- | --- |
| **blocker** | 内容/证据缺失、错、读不到；正文被遮挡；关键条件被裁掉 | 立即修；不进入全套 |
| **major** | 第一眼不是本页焦点；层级平；图只是装饰；连续页同构且无比较理由；排印不可读 | hero pages 清零后再扩展；全套中要逐项处理或明确记录取舍 |
| **minor** | 局部间距、标点、单页细节、可再优化的质感 | 可在全套阶段处理；不阻塞 |

不设 1–10 分，也不把“通过/不通过”写成审美结论。
**major 清零**是扩展条件；minor 可以带着走，但要在记录里保留。

## 两轮，怎么算一轮

完整新稿的 hero pages 至少回看两轮。轮次不是目标，**证据**才是：

1. **第一轮**：看三张实际渲染，列出 3–5 个最明显的问题；只改最影响结果的
   1–3 项（通常是焦点、尺度、构图），重新渲染。
2. **第二轮**：把 before/after 并看，检查修改是否解决了原问题、是否引入新问题；
   再决定扩展或继续修。
3. 全套完成后再做一次 **contact sheet + 逐页目标尺寸**复核，修共享 CSS 后回看受影响页。

如果第一轮已经没有 major，也要在扩展前复看一次（可结合全套 contact sheet），
不能以“检查通过”代替；如果两轮后仍有 major，继续修，不靠增加轮次数量或换背景色凑数。

一轮不是：重跑检查器、改一个 CSS 值、生成截图但没看、写“已优化”。
一轮必须留下：**页/版本、看到的问题、改了什么、回看结果**。

## 证据

- 1600×900 的页面截图，以及目标观看尺寸的截图；现场投影另看实际距离。
- 全套 contact sheet（缩略图）用于看轮廓、密度和重复。
- hero pages 的 before/after；只贴 after 不能证明改进了什么。
- 交付格式的实际回读：PDF/PPTX 的字体、图片、图表和页数。
- 含动效时实际播放，看到入场前、中、完成态；静帧不能证明运动。

“我看了”不是证据；**指出哪一页的哪一个关系，改前是什么、改后是什么**才是。

## 全套复核

1. **contact sheet**：封面之后，标题是否总在同一高度？内容是否总是一排等重栏？
   图片是否总占同样大小？连续页是否只是同一骨架换字？
2. **逐页目标尺寸**：用 [视觉审稿](visual-quality.md) 的观察表，看第一眼、路径、
   空间、排印、素材、风格落地和语义完整性。
3. **设计信号**：运行 `scripts/design_signals.py` 读取字号/字体/颜色/对齐/留白/
   图像/行长/卡片等可观测信号。它是提醒，不是分数；逐条判断是否成立，
   不要为了让信号消失而机械改值。
4. **最终格式**：打开 PDF/PPTX 回读；HTML 正确不等于导出正确。

## 什么不算完成

- 几何检查通过、没有溢出、没有重叠。
- 只看了封面，或只看了高分辨率局部。
- 生成了全部截图但没有逐页看。
- 只写“更精致”“更高级”“符合参考”，没有可定位的页与关系。
- 只改颜色、圆角、阴影或动画，没有动焦点、尺度和构图。
- 图位仍是占位图，或图片内容/裁切未核对。
- 导出的 PDF/PPTX 未回读。
- 用 `design_signals.py` 的报告代替目检；信号清零不等于好看。

## 审稿记录模板

```md
## 2026-01-01 · hero v2

- 页/版本：p1 封面 v2；p4 机制页 v3；p7 signature v2
- 第一眼：p4 先看到右侧截图，但本页要讲的是左侧三个阶段
- 问题：阶段标题与说明同权；截图裁掉了底部条件；p1 标题与副题差 1.4×
- 改动：阶段标题提到 56px、说明降为 26px；截图改 contain 并补条件图注；封面标题 112px
- 回看：p4 第一眼回到阶段标题，条件可读；p1 尺度成立，但副题仍偏长，下一轮处理
- 仍未解决：p7 的图注与页码争抢底部；等图回填后复看
```
