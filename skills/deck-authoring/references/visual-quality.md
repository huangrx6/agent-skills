# 视觉设计与审稿

目标是让观众看清结论、理解证据，并在整套页面中保持注意力。几何检查负责发现可测错误，
视觉审稿负责判断重点、节奏、构图与观看体验，两者都需要完成。

## 从信息关系选择结构

先写每页结论与证据，再决定空间关系。下面是设计任务的映射，不是新增的 spec 页型。

| 信息关系 | 当前可用结构 | 设计重点 |
| --- | --- | --- |
| 一个结果及其意义 | `content-text`，`role:metric`，或 `title` | 数字、基准、解释分层；需要多个组件时用图表或双栏，不把长段正文一起放大 |
| 两个方案比较 | `two-column` 或 `chart` | 两边采用相同维度，标清推荐依据，保持可比尺度 |
| 前后变化 | `content-image` 或 `two-column` | 对照位置一致，变化点有标注，保持原始证据 |
| 分层架构、关键流程 | 外部结构图接 `content-image` | 节点和关系可追溯，保留可编辑源；不能靠生图猜连线 |
| 阶段推进 | `timeline` | 时间间隔、阶段输出与下一步明确；节点太多拆页 |
| 判断与依据 | `content-text` / `content-image` / `chart` | 先显结论，再给证据与解释，三者视觉层级清楚 |

当前没有原生表格、架构或指标卡页型。需要这些能力时，可以选择适配的已有结构、
接入外部矢量素材并说明编辑边界，或扩展 schema 与渲染器后再使用，不能写未实现字段。

## 为观看场景设计排印

在 brief 明确观看距离，并可在 spec 写 `deck.delivery`：

| delivery | 重点 | 验收方式 |
| --- | --- | --- |
| `live` | 少条目、强结论、可远读的正文与图表标签 | 以目标投影尺寸预览；不能只在编辑器放大检查 |
| `async` | 足够上下文、解释完整、清楚的小标题 | 在普通笔记本窗口实际阅读 |
| `printable` | 来源、单位、页码、密集数据可辨 | 按目标纸张尺寸检查 PDF |

1600×900 设计空间下，`check.py` 对 live 的正文 28px、图表标签 22px，以及 async
的正文 20px、图表标签 14px 给出偏小提示；这些是提醒起点，不是能保证远读的通用标准。
未声明 delivery 时不猜场景，不自动更改字号。字号、行高、行长和字重一起判断。

中文排印需目检：标题断行是否完整、标点是否孤立、数字和单位是否分开、中英文字体
是否协调、同层级是否使用一致排印。标题可以自然换行；不要为了守住单行而删掉关键事实。
结论页与章节页可以大字，附录可以密集，但要能说明服务什么阅读目标。

## 风格与素材

每份 deck 自建视觉表达，结构组件和测量接口可以复用。风格先确定字体组合、层级、
网格关系、留白、配色角色，再决定是否需要纹理与装饰；装饰不能替代内容重点。

文字色可显式声明，也可按印刷风格派生。主色是否能做文字取决于实际背景与对比度，
不按颜色名称禁止。复杂图片背景上的文字使用可验证的实底或遮罩，再逐页目检。

真实截图和品牌素材优先保持原貌。信息截图与结构图用 `contain` 展示全貌；照片可用
`cover`，但要明确焦点并检查裁切。当前 fit/focal 通过项目 skin 的 `object-fit` /
`object-position` 表达，尚不是独立 spec 字段。不同图位可按稳定元素选择器设置。

## 三轮视觉审稿

1. **整套缩略图**：检查是否每页同构、强弱是否有节奏、章节是否可辨、字体与色彩是否一致。
   为连续比较保留同构是合理的，不为了变化破坏可比性。
2. **逐页实际尺寸**：先找唯一结论，再检查数据、来源、图表系列、图例、图片焦点、
   文字层级与留白。空白不自动意味着需要填充；增加元素必须提供信息。
3. **最终格式回读**：把实际交付的 PDF / PPTX 打开或渲染，检查页数、所有文字与数据、
   字体替换、图片裁切、图表类别与系列。HTML 正确不能证明 PPTX 正确。

每个新风格至少检查：最长标题、最密正文、稀疏结论、双栏、图文、图表和品牌页脚。
图表应覆盖多系列、长标签、正负值（适用的图形）、深浅背景。失败先定位原因，再改对应层。

## 修复顺序

先确认事实与信息没有遗漏 → 换合适结构 → 收短文案或拆页 → 调整间距与素材裁切 →
最后尝试字号降档。不能通过删系列、隐藏文字、降低对比度阈值或把信息烤进图片来消除报错。

`render --repair` 的实现只会尝试未声明的字号档，不会替你完成上面的内容判断。
`--candidates` 的几何评分只用于发现更合适的候选；留白、主体重量和叙事节奏仍需审稿。
