# 返工清单：这些错已经犯过，别再犯

每条都是真实返工过的。交付前逐条过一遍，比事后改十轮便宜。

## 一、版本与目录

| 现象 | 规则 |
| --- | --- |
| 开 v2 时直接沿用 v1 的风格 | 新版本第一件事是**重新选参考**，旧风格不自动继承 |
| 换了讲的主题，却接着叫 v2 | **vN 是同一份 deck 的第 N 版**；换主题 = 新 deck，新建主题目录从 v1 起 |
| 在产物上做字符串手术改版面 | 改**生成器/模板**再重出；手工修补 HTML 会破坏嵌套，编译器"修复"后内容对不上 |

## 二、字体

| 现象 | 规则 |
| --- | --- |
| 部分文字不是声明字体（混进 PingFang/Menlo） | 交付前 `pdffonts` 核对，只应出现声明过的字族。常见漏点：等宽栈里的中文、SVG 图注、页脚、表格单位 |
| 标题断字、出现方框 | 落版前 `font_repos.py --coverage` 跑一遍，缺字改成中文或代码写法 |
| 正文字族和标题字族各说各话 | 默认**一个字族承担全部文本**（等宽只给机器标识）；确需双族时写清角色与例外 |
| 表格用展示体排 16px，糊成一团 | 展示体只做标题/声明/图内标签；正文与表格要么用正文字族，要么把字号压到正文级、去掉伪粗体 |

## 三、版面

| 现象 | 规则 |
| --- | --- |
| 每页底部都是"三块 + 颜色条" | 底部至少四种：三块 / 一行三段 / 一句判断 / 两栏文字；`rhythm_check.py` 会数出来 |
| 页面骨架千篇一律 | 单一骨架不超过全书 45%，相邻两页不同构（`rhythm_check.py`） |
| 文字页左上一坨、下方大片空白 | 文字页要按版面填满：编号清单、分栏对照、垂直居中；不要默认左上角堆文字 |
| 表格列对不齐 | `table-layout: fixed` + `<colgroup>` 定宽，表头与正文才会同列 |
| 尾页直接放一页内容 | 每套 deck 都要有**设计过的封面与尾页**；尾页是收束，不是最后一个知识点 |

## 四、过程

| 现象 | 规则 |
| --- | --- |
| 用户指出改底部，却顺手改了字体和结构 | 改动范围 = 用户指出的范围；其它问题列出来，不擅自改 |
| 源码改了、截图/PDF 没变 | 每次构建后跑 `build_verify.py` 比对源码与产物的页签名，不一致就停下修结构 |
| 只看缩略图就说"改好了" | 改完必须看那一页的**单页截图**，缩略图看不出列错位、字糊、缺字 |
