# 示例：异常处理规范产出样例（虚构项目）

> 本项目设定：虚构公司 "NovaPay"（与其他 skill 示例同项目），Java 21 + Spring Boot。
> 演示用本 skill 产出的四件套交付物：错误码注册表 → 异常映射表 → 全局异常处理器 → 失败路径测试。
> **本示例不抄用、仅作参照——实际项目以自身技术栈和错误契约为准。**

## 文件

- `error-contract.example.md` — 错误码注册表 + 异常映射 + 全局处理器 + 失败测试的端到端示范

## 要点

1. **失败分类先行**：先分 INPUT/BUSINESS/AUTH/CONFLICT/RATE_LIMIT/DEPENDENCY/SYSTEM，再定状态码和错误码。
2. **错误码稳定**：code 是机器契约，调用方按 code 分支，不解析自然语言。
3. **统一错误出口**：全局处理器负责映射、脱敏、traceId 透传、未知兜底，业务层不构造 HTTP 响应。
4. **幂等衔接**：重试写操作有幂等保护；HTTP 幂等键契约归 api-contracts。
5. **四件套齐全**：注册表 + 映射表 + 全局处理器 + 失败测试，缺一不算完成。
