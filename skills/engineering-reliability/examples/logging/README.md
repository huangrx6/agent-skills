# 示例：应用日志规范产出样例（虚构项目）

> 本项目设定：虚构公司 "NovaPay"（与其他 skill 示例同项目），Java 21 + Spring Boot。
> 演示用本 skill 产出的五件套交付物：事件目录 → 字段目录 → 存储策略 → 敏感字段策略 → 测试计划。
> **本示例不抄用、仅作参照——实际项目以自身技术栈和日志平台为准。**

## 文件

- `logging-spec.example.md` — 五件套端到端示范（事件/字段/存储/敏感/测试）

## 要点

1. **单点记录**：同一失败只在最终责任边界记录一次（统一错误出口）。
2. **结构化优先**：JSON Lines 一条一行；关键上下文进字段不进 message。
3. **双流输出**：人读流（控制台文本）+ 机器读流（JSON），字段语义一致。
4. **error.code 衔接**：日志 error.code 复用 exception-handling 错误码注册表值。
5. **审计分离**：审计事件不受普通采样/清理影响，降级可观测。
