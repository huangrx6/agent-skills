# 区域与尺寸测量

## 选择探测器

| 问题 | 优先命令 |
| --- | --- |
| 画布/缩放 | `info` |
| 卡片宽、gap、外边距 | `runs` |
| 复杂水平/垂直分割 | `bands` |
| 需要全局坐标辅助 | `grid` |
| 小区域精读 | `crop` |
| 实心背景/色块 | `pick` |
| 主色与系列色 | `palette` |

## Runs

选择穿过空白区域的扫描线，避免文字和图形把色段打碎。

近白页面可逐步降低容差；`runs` 无法区分时不要直接断言没有边界，应使用 `pick`/裁剪复核。

## Grid

Grid 是定位工具，不是事实来源本身。不要因为用了 5% 网格就把区域边界强行吸附到 5%。

## Bands

Bands 输出灰度突变候选，必须结合原图判断是卡片边缘、文字行还是分割线。

## Scale

如果截图明显被缩放：

- 所有事实先保留截图 px；
- 换算比例标 Medium；
- 不在没有证据时强行归一到 1440/1920。
