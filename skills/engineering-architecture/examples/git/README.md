# 示例：Git 工作流端到端场景（虚构项目）

> 本目录演示用本 skill 执行 Git 操作的典型场景。
> **示例中的 commit hash 和分支名是虚构的，仅作流程参照。**

## 文件

- `git-workflow.example.md` — 多场景端到端示范（功能开发/合并/回退/worktree/紧急修复）。

## 要点

1. **先看再改**：任何操作前 `git status`；
2. **默认 dry-run**：自动化提交先输出计划；
3. **保护历史**：共享分支不 rebase，用 revert；
4. **worktree 隔离**：并行任务不混在主工作区；
5. **可回退优先**：危险操作前记录 HEAD 恢复点。
