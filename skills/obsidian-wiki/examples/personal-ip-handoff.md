# 示例：缓存读路径的配图交接

下面演示“只有文本能力时”的交付。示例文件留在 skill 中，因此参考图使用相对 Markdown 链接；
写入真实 vault 时先复制参考图，再改成库内路径。以下输出路径是预定位置，当前没有成图。

这里以一种简化的旁路缓存读路径为例：先读缓存，命中则返回；未命中才读数据库、回填缓存并返回。
它只描述读取成功的分支，不涵盖写入一致性、并发、过期和故障处理。
