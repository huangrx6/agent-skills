# 技术配图

用于知识文章的配图判断、制作与检查。完整写作、实质性扩写或重组文章时执行以下流程；
只改字、改名或维护 MOC 时不顺带生成图，修改的知识影响已有图时仍需核对该图。

## 从判断到落地

### 安排文章结构时，找出图能解决的问题

结合读者目标、已有正文和配图判断，不等正文写完再装饰。重点留意读者需要在脑中拼接的
层级、路径、时间顺序、状态变化、边界与相互关系；也考虑图能否帮助长文建立整体直觉。
不必逐节填写清单。对有价值的候选图，在工作过程中简要确定“解释什么、已有依据、放在哪里”，
再选以下去向；这些制作判断不写进成品文章。

| 遇到的情况 | 处理方式 |
| --- | --- |
| 图能让关键关系一眼可见，内容依据充分，现有图尚未覆盖 | 生成；选择能表达该关系的图形，不等用户逐张提醒 |
| 已有准确、清楚且可使用的图覆盖同一问题 | 复用；内容或布局有变化时修改，不重复生成 |
| 简短定义、少量要点或简单步骤已经清楚；重点是精确数值、参数、代码或命令 | 优先保留文字、表格或代码；只有额外的关系解释价值才配图 |
| 图只是把段落装进卡片、放通用图标，或重复相邻图且没有增加理解价值 | 不生成；长文也可先改善段落与排版 |
| 关键节点、顺序、边界尚未确定，图会把猜测表现成确定事实 | 先核实；不能核实时暂缓，必要时仅画有依据的部分并明确范围 |

用户明确要求配图时执行其要求，并选取最有解释价值的内容；必要事实仍不可编造。
用户明确不要图或只要方案、提示词时按指定交付。不要以固定字数、章节数或图片配额作判断。

### 决定配图后，完成制作与插入

内容关系和关键标签确定后再制作，不必等全文完成，也避免在内容尚未确定时反复生成。
先核对现有资产和可用工具，再按下文选择图形与风格。已获授权的文章完善任务中，
有明确价值且工具可用的配图应实际完成、保存到附件目录，并插入对应解释附近，不能停在“建议加图”。
涉及个人 IP 时读取 [个人 IP 与生图交接](personal-ip.md)，实际检查参考图和工具是否支持带图输入。
没有生图能力、不能输入角色参考、用户要自己生成或生成失败时，在对应段落留下醒目的 `[!todo]+`
待生成块：真实可访问的参考图、完整提示词、确定的输出位置和验收重点；保留足以理解知识的正文。
能用 Mermaid、SVG 等准确完成的知识图仍可完成；需要角色的部分按交接规则处理，不能悄悄改成人物缺席。
不创建空图片占位或嵌入尚不存在的文件，不把提示词当作已完成的图片。

### 交付前，检查图是否真的帮到了阅读

查看实际产物，核对标签、方向、包含关系、适用条件与正文一致，确认嵌入路径有效。
在可用预览中检查正常阅读宽度下的中文、连线、裁切与留白；未能查看渲染时如实说明。
有技术错误就修正；过密则精简或拆图；无增益则移除本次新增图，不能因已经生成就硬塞进文章。
正文有后续修改时再次核对相关图。完整写作任务的交付用一句话说明实际新增、复用的图及作用；
未完成的图说明具体原因和待生成块位置，避免只说“按需配图”。不另建全库配图台账；
用户补回图片后检查再替换该块，维护方式见个人 IP 交接规则。

## 统一视觉语言，保留内容自由

默认采用与用户小研究员 IP 协调的清爽手绘知识图解：白色或暖白底、轻微纸感、深灰手绘轮廓、
柔和色块和充足留白。用少量铅笔/蜡笔质感增加亲切感，文字、连线和信息区保持清楚；
不是每张都铺纸纹、方格或便签。技术标签用易读的字形，不要求模仿参考图里的手写标题。
纯工程图可用更规整的矢量线条，用户指定其他风格时服从本次要求。

统一感主要来自字体层级、线条粗细、圆角、图标语言和间距，不要求所有图片用同一套颜色。
根据内容选择协调的少量强调色，蓝色、绿色只是可选方案；同一文章中的相同对象与语义尽量保持同色。
文字和背景要有足够对比，颜色之外仍用标签、位置或形状区分含义。
角色的蓝色毛衣属于身份特征，不代表所有节点必须蓝色；暖黄可强调灵感，其他语义色随内容选择。
参考图里的表情和动作是可能的叙事手段：思考用于提出问题、讲解用于指向关键关系、记录用于实验观察。
不把人物贴满每个节点，也不固定在每张图右下角；需要人物时使用同一 IP，没有作用时可以不出现。
角色参考负责身份，内容材料负责知识，其他风格参考负责版式；不要混淆三者或复制整张角色设定板。

## 信息决定图形

先明确这张图要解释的问题，再选分层、流程、时序、状态、对比、关系或其他适合的形式，
不把所有知识强制画成流程图。长文可拆成围绕不同问题的图，避免把全文挤进一张海报。
标签简练且术语准确；节点、方向、包含关系与适用条件必须有内容依据，不能为了美观补出技术细节。
箭头要有实际语义，普通关联不默认画成因果或执行顺序。优先减少交叉，必要交叉时区分跨越与连接。

画幅随结构与插入位置选择；16:9 适合部分横向图，但不是默认硬约束，纵向分层或时序可用更合适的比例。
检查笔记常用阅读宽度下的文字大小、边距、连线和图文对应；不要靠缩小标签容纳过多内容。

按可用能力和交付目的选择工具，不强制绑定绘图服务或另一项 skill。
“矢量风格”是视觉描述，不保证生成文件是 SVG；需要可编辑图时选择能保留结构的格式，
直接插入文章时选目标阅读与发布环境支持的图片格式。产出后核对术语、箭头和文字可读性，
生成成功不等于技术正确。附件沿用库内目录；已完成图片的提示词保留在制作文件中，
未完成图片按交接规则放入可见的待生成块，发布前完成、移出或明确保留草稿状态。

## 可复用生成提示词

需要人物的图使用 [个人 IP 与生图交接](personal-ip.md) 的身份约束和
[待生成块模板](../assets/templates/image-task.md)。每张提示词写出本图的问题、必要节点、关系、
布局、人物的解释作用和精确标签；据此展开为可单独复制的完整任务，不要求外部模型读 skill 或整篇文章。
不需要人物时去掉角色部分，保留本页的信息、视觉和准确性要求，不为了使用 IP 强造角色戏份。
