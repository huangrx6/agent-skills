# 示例：服务韧性产出样例（虚构项目）

> 本项目设定：虚构公司 "NovaPay"（与其他 skill 示例同项目），Java 21 + Spring Boot 微服务。
> 演示用本 skill 产出的超时预算、重试责任、舱壁隔离、故障注入端到端示范。
> **本示例不抄用、仅作参照——具体 Timeout/Retry/Limit 数值必须由服务的负载和故障实验决定。**

## 文件

- `resilience-design.example.md` — 关键路径超时/重试预算 + 依赖韧性策略 + 故障注入计划端到端示范

## 要点

1. **从入口 Deadline 向下分配**：总预算（如 1.5s）按调用链层数拆分。
2. **一个失败只一个明确层重试**：网关不重试，SDK 不重试，服务内部统一层重试。
3. **舱壁隔离租户**：每个租户独立连接池和线程池，避免单租户拖垮全实例。
4. **降级显式记录完整度**：缓存兜底必须标注"陈旧"和最大过期时间。
5. **故障注入验证假设**：每个保护策略必须用真实故障实验证明。
