# 访客模式与视觉方向设定

动手画线框或写样式前，先确立两件事：**访客来这里做什么（访问模式）**，以及**这个产品独有的视觉命题（设计方向）**。模式决定视觉表达能走多远，命题决定做出来的界面属于这个产品，而不是任意一套模板的换皮。

---

## 一、三类访问模式判定表

先按页面的主任务判定访问模式。同一产品内不同页面可属不同模式（例如官网落地页属 Persuade，文档站属 Read，控制台属 Operate），不得把落地页的戏剧化照搬进工作台，也不必让品牌页变成枯燥的后台表单。

| 维度 | Operate（工作台 / 工具） | Read（阅读 / 文档） | Persuade / Experience（官网 / 展示 / 体验） |
| --- | --- | --- | --- |
| **访客核心意图** | 高效完成任务、监控状态、做操作决策 | 理解概念、查阅参考、顺畅定位上下节 | 判断价值主张、建立信任、体验作品并转化 |
| **第一身份** | 同品类里极好用的生产工具 | 清晰易读、寻路明确的专业文档 | 视觉本身即说服力与体验载体 |
| **视觉世界边界** | **只借 4 项**：字体、色板、密度、1 处标志性动作 | **掌控外框，让出正文栏** | **可主导骨架与材质，但零件必须真可用** |
| **导航与控件** | 严格遵循平台标准控件与常规心智模型 | 保留标准目录、面包屑与上下文寻路 | 可融入主题载体，但链接与按钮一眼可辨可点 |
| **色彩角色** | 动作、选中、状态、数据系列、壳层区分 | 外框承托气质，正文栏高对比克制底色 | 色彩可大面积主导情绪与第一视觉记忆 |
| **动效取向** | 快速反馈与状态连续，禁止开屏等待编排 | 极轻过渡，绝不干扰阅读视线 | 可有 1 处精心编排的焦点时刻 |

## 二、Operate（工作台 / 工具）模式铁律

在工作台界面中，熟悉同类工具的人必须在**注意到视觉风格之前**就知道所有功能在哪。界面首先是该品类的一流产品，视觉风格服务于它。

### 1. 视觉世界仅限四项贡献（严格边界）

无论灵感来自何种领域，视觉世界在 Operate 界面中**只允许贡献以下四件事**：

1. **字体（Type）**：建立清晰的角色尺度与气质，正文与数据优先扫描效率与稳定性。
2. **色板（Palette）**：色板要真正干活——壳层底色（着色侧栏或顶栏、微染画布）、语义状态色、数据序列色、选中态与焦点态。**满屏中性灰加一个高亮强调色不是克制，而是未完成的默认模板。**
3. **密度（Density）**：匹配使用频次与决策复杂度（高频交易/运维偏紧凑，低频向导/配置偏舒展）。
4. **一处标志性动作（Signature Move）**：在已经干净整洁的界面上，给出一个与业务强绑定的独特视觉表达——例如把服务健康拓扑画成地铁线路图、把排班表按列车时刻表的列律编排。如果一个设计方向只剩下“换了套配色”，说明还没找到它的标志性动作。

**视觉世界绝不能接管以下三件事**：
- **不接管布局骨架**：工作台不能伪装成报纸、海报或印刷品。
- **不接管导航模型**：沿用清晰的侧栏、顶栏或命令面板，不发明让用户重新学习的奇巧导航。
- **不接管标准控件**：按钮、Tab、输入框、选择器、筛选器、可排序表格必须遵循 Web 或原生平台标准交互；禁止套用终端功能键底栏、仪表盘金属表圈、手绘账本纸格等“道具化戏服（Costume）”。

> 检验标准：如果工程师无法用标准平台组件实现这张设计稿，那它只是“工具的插画”，不是工具本身。

### 2. 真实内容与状态设计

- 方案与原型必须填入**真实产品名、可信量纲的数据、真实标签**，并主动展示至少一个高价值状态（如告警、服务降级、筛选无结果），禁止用空白占位瓷砖敷衍。
- 语义状态色（严重告警红、降级琥珀黄）叠在产品色板之上且**仅在表达状态时出现**。
- 随时间波动的核心指标，应附带近期趋势上下文并标出变化起点，而不是孤零零摆一个大数字。

### 3. 方案对比与隐名自检

- **多方案对比改组织、不堆装饰**：备选方案应在导航模型（侧栏 / 顶栏 / 命令优先）、工作区划分、领先数据、信息密度和标志性动作落位上形成缩略图级差异；靠增加纹理与装饰物制造的“变体”是在往错的方向走。
- **隐去产品名自检**：遮住名称后问三个问题——它一眼看去像这个品类的专业工具吗？访客能直接完成核心任务吗？它既达到品类顶尖的整洁度，又比通用后台更具辨识度吗？若它先像某个道具或艺术品，再像工具，立刻收回到上述四项边界内重构。

## 三、Read（阅读 / 文档）模式铁律

在阅读界面中，读者的核心问题是唯一主角，理解效率与寻路感在任何滚屏位置都不能断裂。文档像文档，指南像指南，文章像文章，更新日志像更新日志。

### 1. 外框承托风格，主栏回归安静

- **视觉世界掌控外框（Frame）**：报头（Masthead）、导航栏/着色侧轨、整体画布底色、标题与章节开篇、页眉运行标题（Running Head）、页边注系统、编号体系，以及代码块/表格/提示框的装帧风格。在这里充分兑现品牌色板、字体与标志性动作，让页面具有不可替代的归属感。
- **阅读主栏保持绝对安静（Calm Column）**：
  - 使用舒适可读的正文字体，与底色保持扎实对比度；
  - 维持真实阅读行宽（Web 端约 60–75ch，正文基准 16px 起）；
  - **正文背后禁止任何装饰纹理、动态效果或干扰图形**；
  - 等宽字体专用于代码、参数、标识符与细小元数据，默认不用于长段正文或主标题。
- **灵感优先取自出版传统**：参考书、字体样本册、时刻表、田野调查指南、技术手册、学术旁注体系、报刊导览索引——避免套用仪表盘或科幻控制台戏服。

### 2. 结构化寻路与自检

- 首屏必须交代四件事：导航与当前位置、直击问题的标题与导语、清晰的正文栏、清晰的推进路径（目录大纲、小节标题、上一篇/下一篇）。
- 用最难排的真实内容做样张验证（真实代码段、多列参数表、技术图示），绝不用占位假文。
- **双问自检**：
  1. 读者能否瞬间知道自己在哪、下一步去哪，并舒适地连读 10 分钟？
  2. 遮住产品名后，它是否看起来像随便哪套开源文档模板？若是，把风格推进到报头、侧轨、底色与开篇里；若正文栏已经开始难读，说明风格侵入了主栏，立刻退回外框。

## 四、Persuade / Experience（官网 / 展示）模式铁律

在说服与体验型界面中，设计品质本身就是产品能力的证据。视觉世界可以成为页面骨架的载体，但仍受两条铁律约束。

### 1. 做“载体”，绝不做“画报”

- **拒绝两个极端**：一端是把整屏画成一张没有工作零件的静态海报/封面；另一端是套用通用落地页模板（居中大标题 + 副文案 + 按钮 + 下方三张等宽特性卡），只在上面贴一层品牌配色。
- **载体与零件共存**：如果页面以建筑立面、折页书册或展示柜为结构载体，导航放在立面上就必须一眼像可点链接，文字落在材质上必须高对比可读，操作按钮必须明确可交互，下一屏自然承接为内容区而非继续作画。
- **单物件单视角一致性**：若以真实物件作为空间隐喻，整页只以一个尺度、一个视角呈现该物件（例如摊开的书只有左右两页和一条中缝，不会凭空长出第三页或另一本侧边小书）；更多内容顺延到下一页跨页，而非复制多个缩微物件。

### 2. 首屏即见可工作的核心转化动作

- **Persuade 模式**：首屏必须同时做到三件事——一句说清价值主张、露出该品类真正可交互的核心动作、呈现只有本产品能证明的事实证据。
  - 核心动作必须是**可工作形态**（航空公司的航线与日期检索框、诊所的可约时段、电商的加购控件），放一个空泛的“了解更多”跳转链接不算完成转化设计。
- **Experience 模式**：作品或交互体验本身从首屏第一像素直接领衔，不套冗长营销开场白。
- **方案演进方向**：探索备选方向时往“更坚定、更充分利用同一视觉世界的材质与结构”推进，而不是回退到更平庸的左右分栏 Hero。

## 五、设计前的两遍视觉命题工作法

开展新界面或重大改版时，严禁直接堆代码，按两遍法先立住命题：

### 第一遍：从题材本身长出紧凑设计规划

若需求未明确产品与受众，先根据上下文拟定具体产品题材、目标受众与核心任务并确认。所有审美选择必须源自该题材的真实材质与行业语境（面向 8–11 岁儿童的创意玩具界面，与服务金融分析师的终端工作台，必须在基因上截然不同）。写下四项紧凑规划：

```text
1. 色彩（4–6 个命名色值）：画布底色、抬升表面、主/次文字、唯一主强调色、语义色策略
2. 排版（1–2 个字族及角色）：标题/展示声部、正文声部、等宽数据声部，写明字重与行宽
3. 布局（一句话概念 + ASCII 线框 + 对齐策略）：明确左对齐/居中/非对称依据与视觉重心
4. 唯一性原则（1 个 Signature Move + 1 条反目标）：明确页面凭什么被记住，以及绝不做什么
```

### 第二遍：反向对照简报去模板化

写代码前做一次反身自检：假设换一个毫无关系的同类产品需求，这套规划里的配色、字体、Hero 构图或卡片结构是否会原封不动复现？
- 只要某条属于“随手掏出的惯性默认”，就推翻重写并写明改了什么、为什么更贴合本题材；
- 若用户简报明确指定了某种风格，以简报原话为准，不擅自反叛；只有在简报留白的自由轴上，坚决拒绝落入惯性模板。

## 六、克制与大胆的平衡准则

- **把大胆花在一处（Spend Boldness in One Place）**：每屏或整站只让一个核心元素承担记忆点，其余所有区域保持安静、克制、有序，删掉一切不服务于核心命题的装饰。
- **写样式时防选择器冲突**：避免宽泛元素类（如 `.section`）与组件类（如 `.cta`）的 `padding`/`margin` 互相覆盖抵消；先定义语义间距与布局原语，再写局部覆写。
- **上线前减法检查**：完成初稿后通屏审视，主动拿掉至少一件多余的装饰性边框、徽章、投影或副标签；在“精致圆滑”与“坚定鲜明”之间犹豫时，只要工艺底线全绿，选择更坚定地表达既定世界。
