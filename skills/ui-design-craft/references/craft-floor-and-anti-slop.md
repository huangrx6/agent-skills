# 工艺底线与反 AI 模板红线

工艺底线只守住工程与视觉的下限，不替你决定创意方向；只有底线全部达标，视觉方向才站得住脚。凡标记为**硬禁令**的条目不可豁免；其余标记为**惯性默认**的条目，除非用户简报明确点名要求，否则不得在自由轴上随手使用。

---

## 一、交付必检：9 项工艺底线（Craft Floor）

以下 9 项是对**最终渲染结果**的实测要求，而非纸面意图。应在一次真实渲染视图中批量核验（而非走过场式口头确认）：

| # | 维度 | 量化与实测底线 | 常见失守点 |
| --- | --- | --- | --- |
| 1 | **对比度** | 正文与占位符 ≥ `4.5:1`；大号文本（≥18pt / 14pt 粗体）、控件边界与焦点环 ≥ `3:1`。有色底面次级文字须从底色或前景色派生，**绝不用中性灰** | 浅灰占位符、暗色模式下低亮蓝字、半透明白字压图 |
| 2 | **景深与阴影** | 阴影必须包含方向偏移与柔和模糊（如 `0 4px 16px`）；零偏移彩色光晕属于装饰噪音，禁止当景深用 | 卡片四周均匀发亮霓虹光晕 |
| 3 | **空间节奏** | 组内紧、组间松，**标题上方间距必须大于下方间距**；核查真实计算后的 `margin`/`padding`/`gap` | 全页一律 `16px` 或标题紧贴上一段、远离自身正文 |
| 4 | **排版尺度** | 正文行宽 `45–75ch`（长文 `60–75ch`）；展示标题上限 `6rem`；紧字距底线 `-0.04em`；标题开启平衡换行；用真实长文案验证全断点无溢出 | 假短文案看着齐、换真实中文或长英文即撑破 |
| 5 | **动效节制** | 整页至多 1 处精心编排的焦点动效，拒绝每段重复相同入场；默认态即刻可见，使用指数减速曲线；合乎预算时可善用 `clip-path`、遮罩、局部 `backdrop-filter` 与阴影 | 全页每个区块清一色 `fade-in-up` 滚动触发 |
| 6 | **全状态覆盖** | 补齐 `hover`、`focus-visible`、`active`、`disabled`、`loading`、`error`、`empty` 态；所有控件真可交互，支持纯键盘与响应式布局 | 只做完理想数据的静态展示态 |
| 7 | **浏览器默认表面** | 对文字选区、输入光标、滚动条、焦点环、下划线偏移与等宽数字进行主题化，不留浏览器原生蓝/灰默认值 | 精致暗色主题里一选中文字变成刺眼默认蓝 |
| 8 | **界面文案** | 说产品的真实语言：按钮写明具体动作与对象，错误写明原因与恢复办法，无占位废话 | “确定 / 取消”、“出错了，请稍后重试” |
| 9 | **需求完整度** | 简报中每一项业务需求均真实落地，且访客在数秒内可定位找到 | 漏掉关键筛选、导出、状态提示或二级操作 |

## 二、AI 模板脸校准：5 类高频“一眼生成”特征

当前大量 AI 生成界面高度聚类于以下 5 套惯性组合。它们本身并非在任何题材下都违法，但只要简报未主动点名，随手落入其中即意味着没有为本题材做设计判断：

1. **暖米白编辑风套路**：接近 `#F4F1EA` 的暖米背景 + 高对比衬线展示标题 + 陶土/暖橘强调色（如 `#D97757`）。
2. **极客暗黑荧光套路**：近纯黑底色（`#0B0B0B` / `#111`）+ 单一高饱和荧光绿或朱红强调色。
3. **伪报刊线框套路**：满屏 `1px` 细分割线 + 全元素 `0px` 圆角 + 强行套用的高密度多栏报纸结构。
4. **SaaS 卡片套件套路**：把一切内容切成等宽等高圆角卡片 + 全站无论层级一律同一个 `border-radius` + 每张卡底下同一个 `rgba(0,0,0,.1)` 柔灰投影 + 装饰性渐变色块衬底。
5. **无差别模板装饰件（Template Chrome）**：
   - 每个标题上面悬一行拉宽字距的全大写英文眉标；
   - 到处用中点拼接元数据（`A · B · C`）或用带空格破折号构造标签（`LABEL — fragment`）；
   - 把等宽字体无脑用于所有小标签营造“技术感”；
   - 所有链接和按钮末尾机械追加 `→` 箭头；
   - 标题里刻意给某一个词加斜体或变强调色。

> 纠偏动作：发现上述惯性默认时，不要只把颜色调淡了事——直接重写该元素的结构与表达方式，回到本题材自己的语汇。

## 三、完整反模式禁令清单（Refuse）

### 1. 页面骨架禁令

- **等大图标卡片平铺**：不要默认用「顶部小图标 + 标题 + 两行说明」的 3–4 列等大卡片作为页面主结构。卡片是偷懒的默认容器，优先用排版层级、留白亲密性、列表、分栏或真实数据控件组织信息。
- **卡片套卡片（硬禁令）**：绝对禁止在圆角卡片内部再嵌套带边框/阴影的子卡片。二级分组用细分割线、缩进、轻量底色带或间距层级解决。
- **Hero 指标模板**：不要在页头条件反射式地堆砌「特大数字 + 小标签 + 一排辅助统计 + 渐变点缀」。仅当业务确实以核心实时 KPI 领衔时使用，且须附趋势上下文。
- **标题上方眉标 / Kicker（硬禁令，不可豁免）**：禁止在标题上方放置全大写/拉宽字距的分类眉标或装饰性小标签。标题必须凭自身措辞与字形尺度立住，直接删除眉标让标题说话。
- **伪序号（`01 / 02 / 03`）**：除非内容在逻辑上是严格先后步骤、时间线或排名，否则禁止为了“看起来有结构”给并列特性硬加编号。
- **滥用模态弹窗**：无需打断主流程、也不需要保护高风险焦点的轻量任务（查看详情、简单编辑、局部筛选），优先用行内展开、侧边抽屉或原位编辑，不要动辄弹 Modal。

### 2. 表面、层级与装饰禁令

- **渐变文字**：禁止用 `background-clip: text` 给标题或数字做彩色渐变。视觉强调应来自字重、字号、留白与位置，而不是彩虹填充。
- **装饰性毛玻璃与模糊**：`backdrop-filter: blur()` 仅用于明确悬浮于动态/复杂背景之上的浮层（如顶栏、弹层），禁止给静态卡片盲目加毛玻璃。
- **单侧彩色竖条（硬禁令）**：禁止在圆角卡片/提示框的左边缘加一条彩色粗竖条（无论通过 `border-left`、`inset box-shadow` 还是伪元素实现）。表达提醒或分组状态，请使用**完整细边框 + 极淡同色系底色 + 前置语义图标/短标签**。
- **乱用零模糊硬偏移阴影**：`box-shadow: 4px 4px 0` 仅属于明确采用新粗野主义（Neobrutalism）的视觉世界，在其他风格中属于生硬戏服。
- **层级双重声明（幽灵卡片）**：同一容器只能在「细边框」与「带偏移柔和阴影」之间**二选一**；在宽大柔阴影下再叠一圈 `1px` 边框会让边缘发脏。
- **圆角失序与乱用胶囊**：普通卡片圆角控制在 `12px–16px`（工作台密集面板可收至 `6px–10px`），嵌套容器遵守**外圆角 ≥ 内圆角 + 内边距**；全圆胶囊（`9999px`）仅用于小型徽章、开关与紧凑按钮，不用于大面板。
- **凑数可视化**：禁止放没有真实数据意义的 Sparklines、装饰性进度环和空心圆角矩形占位。
- **等宽字体戏服化**：等宽字体只给代码、终端输出、机器 ID、时间戳与数据表数值，不拿来装扮普通标题或段落。
- **系统字体充当品牌展示声部**：品牌展示页或独立视觉世界，禁止用系统默认 sans / Impact / Arial Black 冒充定制展示字体；应引入并托管契合气质的真实字体。

### 3. 图标、图像、材质与内容红线

- **Emoji / Unicode 充当图标系统（硬禁令）**：禁止用 🚀✨⚙️✅ 等 Emoji 或杂乱 Unicode 符号作为正式 UI 图标。统一使用同一套专业图标库或自绘 SVG，保持一致的线宽（stroke-width）、端帽样式与视觉尺寸。
- **粗暴几何遮罩裁切人像/实物**：禁止用 `clip-path: circle()`、多边形或径向渐变生硬裁切摄影主体边缘；要么保留自然构图框，要么使用真实 Alpha 抠图素材。
- **真实插画或干脆留白**：禁止用粗糙涂鸦风 SVG 场景、廉价 `feTurbulence` 噪点贴图模仿手绘插画。区分两类 SVG：
  - **允许且一流**：精确几何图形、架构/流程图、数据图表、清晰动态线条；
  - **禁止**：用代码手搓带透视、光影或人物造型的伪插画。
- **无由来的背景纹理**：`repeating-linear-gradient` 斜条纹、双向坐标网格叠加层，只有在页面本身对应画布、蓝图、测绘或工程标尺时才成立，否则只是视觉噪音。
- **按品类盲选明暗主题**：不因“开发工具就必须暗黑”或“企业应用就必须纯白”做决定，依据使用场景、环境光与工作时长决定默认主题，并做好双主题支持。
- **内容诚实性**：页面声明、指标与配置必须来自真实输入；演示/示意数据须明确标注为示例，不编造虚假数据或用反讽语气掩盖空洞文案。

## 四、浏览器默认表面主题化（Browser Surfaces）

模型最常漏掉、却最能体现“精心打造而非东拼西凑”的细节，是把浏览器自带的默认表面全部纳入设计系统的 Token 体系：

```css
:root {
  color-scheme: light dark;
  --accent: oklch(0.55 0.18 255);
  --accent-soft: oklch(0.55 0.18 255 / 0.18);
  --surface: oklch(0.99 0.004 255);
  --surface-raised: oklch(0.96 0.006 255);
  --ink: oklch(0.2 0.015 255);
  --border-subtle: oklch(0.88 0.01 255);
}

/* 1. 文本选区与输入光标 */
::selection {
  background: var(--accent-soft);
  color: var(--ink);
}
input, textarea, [contenteditable="true"] {
  caret-color: var(--accent);
}

/* 2. 链接下划线呼吸感（避免压穿过字母降部） */
a {
  text-underline-offset: 0.2em;
  text-decoration-thickness: max(1px, 0.07em);
}

/* 3. 统一的键盘焦点环（仅键盘触发，点击不乱亮） */
:focus-visible {
  outline: 2px solid var(--accent);
  outline-offset: 2px;
}

/* 4. 主题化滚动条（标准属性 + WebKit 细调） */
* {
  scrollbar-width: thin;
  scrollbar-color: var(--border-subtle) transparent;
}

/* 5. 数据列与动态数字防抖动 */
.metric, time, td[data-numeric], .counter {
  font-variant-numeric: tabular-nums;
}

/* 6. 原生 select 在 Windows 暗色模式下的前背景色保护 */
select, select option {
  background-color: var(--surface-raised);
  color: var(--ink);
}
```

同时确保 HTML `<head>` 中的 `<meta name="theme-color" content="...">` 与当前主题页底色同步，暗色主题在 `<html>` 上显式声明 `color-scheme: dark`，避免原生滚动条与表单控件在暗底上出现刺眼白框。

## 五、正反例速查对照

| 常见反模式（Refuse） | 工艺级改法（Craft） |
| --- | --- |
| 卡片左侧 `4px` 亮蓝竖条 + 外圈 `1px` 边框 + 大阴影 | 去掉单侧竖条与多重边界；采用单一淡底色 surface + `1px` 细边框 + 前置语义图标 |
| 卡片内嵌 3 张带阴影的小指标卡片 | 取消内层卡片，用 3 列网格 + `1px` 垂直细分隔线 + 清晰字号/字重对比呈现 |
| 标题上方悬一行 `01 · CORE FEATURES` 全大写眉标 | 删除眉标与伪序号，直接用一句具体有力、自足的标题承担信息层级 |
| `🚀 快速开始` 与 `⚙️ 设置` 做导航栏图标 | 替换为同族 SVG 线性图标（统一 `16px` / `stroke-width: 1.5`），图标加 `aria-hidden="true"` |
| `background: linear-gradient(...)` 彩色渐变大字标题 | 使用纯色高对比实色，靠字重阶跃、字号比例与负空间建立视觉焦点 |
