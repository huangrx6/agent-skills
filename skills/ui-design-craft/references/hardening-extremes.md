# 极端数据、表单交互、容错与无障碍加固

只在 3 条完美短英文和满格 Wi-Fi 下好看的界面，远未达到生产就绪标准。本规范系统性加固 6 条生产防线：**极端数据与溢出、多语种 i18n、表单与 URL 状态、网络/错误与并发、中断手势、以及键盘与无障碍韧性**。

---

## 一、极端输入压测矩阵与 CSS 防溢出库

交付前必须用以下 6 类真实极限数据压测每个列表、卡片、弹窗与表格：

1. **超长文本**：100+ 字符连续无空格字符串（长文件名、URL、Webhook 密钥、德语复合词）；
2. **极短与空值**：空字符串、`null`、单字符、空数组（绝不渲染断裂空白框或 `undefined`）；
3. **特殊字符集**：CJK 中日韩混排、4 字节组合 Emoji（👨‍👩‍👧‍👦）、重音符号与双向混排文本；
4. **超大数值**：百万/十亿级金额、高精度小数、负增长百分比（必配 `tabular-nums` 与合适缩写/千分位）；
5. **海量集合**：`50+` 下拉选项、`1000+` 列表项（独立滚动、粘性搜索栏/底栏、虚拟列表或分页）；
6. **高倍缩放与窄矮视口**：`320px` 宽手机、`200%` 浏览器放大、桌面端矮窗口弹窗。

### 生产级防溢出 CSS 基础套件

```css
/* 1. 单行省略（父级 Flex/Grid 必须同时设 min-width: 0！） */
.truncate {
  overflow: hidden;
  text-overflow: ellipsis;
  white-space: nowrap;
}

/* 2. 多行截断 */
.line-clamp-3 {
  display: -webkit-box;
  -webkit-line-clamp: 3;
  -webkit-box-orient: vertical;
  overflow: hidden;
}

/* 3. 允许长连续词（URL / ID / 路径）安全折行，不撑破容器 */
.wrap-safe {
  overflow-wrap: anywhere;
  word-break: break-word;
  hyphens: auto;
}

/* 4. Flex 与 Grid 子项收缩铁律（漏写 min-width: 0 是截断失效头号元凶） */
.flex-child-safe {
  min-width: 0;
}
.grid-child-safe {
  min-width: 0;
  min-height: 0;
}
```

## 二、国际化（i18n）与多语种深度加固

1. **30%–40% 文本膨胀预算**：德语、法语、俄语通常比英文长 30%–40%。**严禁对按钮、标签、表头写死固定宽度**（用 `min-width` + `padding-inline` 随内容自适应增长）：

```html
<!-- ❌ 固定宽度：换德语/长中文立刻溢出或折成两行 -->
<button class="w-24">Submit</button>

<!-- ✅ 内容自适应：保留最小宽度与呼吸内边距 -->
<button class="min-w-24 px-4 py-2">保存配置</button>
```

2. **使用 `Intl` 原生 API，严禁硬编码格式与英语复数**：
   - 日期与本地历法：`new Intl.DateTimeFormat(locale, ...)`（自动支持公历、波斯太阳历 `fa-IR`、伊斯兰历 `ar-SA-u-ca-islamic` 等）；
   - 数值、货币与本地数字：`new Intl.NumberFormat(locale, { style: 'currency', currency })`（自动处理 `1,000.50` vs `1.000,50` 及东阿拉伯数字）；
   - 复数规则交给成熟 i18n 库（如 ICU MessageFormat），严禁手写 `` `${count} item${count !== 1 ? 's' : ''}` ``。
3. **阿拉伯语系与波斯语特殊字符保护**：
   - **严禁清理或归一化零宽非连接符 ZWNJ（`U+200C`）**，波斯语与库尔德语靠它断开复合词连写而不拆词；
   - 存储保留原始字符，但搜索与校验需等价兼容波斯 Yeh（`U+06CC`）/ Kaf（`U+06A9`）与阿拉伯 Yeh（`U+064A`）/ Kaf（`U+0643`），避免键盘变体导致查不到或报错。
4. **语言检测与免翻译保护**：
   - 按 `Accept-Language` / `navigator.languages` 探测语言，**不用 IP 地理位置硬猜语言**；
   - 品牌名、代码标识、CLI 命令、环境变量加 `translate="no"`，防止浏览器自动翻译成乱码。
5. **RTL 逻辑属性**：全站采用 `margin-inline-start`、`padding-inline`、`border-inline-end`、`inset-inline-start` 与 `text-align: start`；对 `dir="rtl"` 页面实地核查箭头与布局镜像。

## 三、表单体验、导航状态与水合安全

### 1. 表单硬规则（无一可省）

- **精准语义属性**：填写有意义的 `name`、`autocomplete`（登录/地址等用标准 token；非认证搜索/配置字段用 `autocomplete="off"` 防误触发密码管理器）、正确 `type`（`email`/`tel`/`url`/`number`）与 `inputmode`；邮箱、验证码、用户名与密钥输入框关闭拼写检查（`spellCheck={false}`）。
- **严禁拦截粘贴**：绝对禁止在密码、验证码、邮箱确认等字段里用 `onPaste` + `preventDefault()` 阻止用户粘贴（会直接击垮密码管理器与无障碍用户）。
- **标签与热区无死区**：每个控件配可点击 `<label htmlFor="...">` 或直接包裹控件；复选框与单选框的图形与文字共享同一连续点击热区，中间不得留空白死区。
- **移动端输入防强缩放**：`<input>` / `<textarea>` / `<select>` 在移动端字体不小于 `16px`，避免 iOS Safari 聚焦时强制放大视口破坏布局。
- **提交与报错体验**：
  - 提交按钮在请求发出前保持可点击（让点击触发明确的字段校验定位，而非灰色禁用让人摸不着头脑），发出请求后切换 Loading 态防重复提交；
  - 校验错误内联显示在对应字段旁并通过 `aria-describedby` 关联，提交失败自动聚焦到**第一个出错字段**；
  - **报错绝不清空用户已填写内容**；服务端必须独立二次校验与防注入，永不盲信前端校验；
  - 有未保存修改离开页面时，通过 `beforeunload` 或路由守卫提醒确认。

### 2. URL 状态深链与水合安全

- **状态同步到 URL**：筛选条件、当前 Tab、分页页码、排序方式与展开面板尽量映射至 URL Query，保证刷新不丢状态、链接可分享。
- **真链接与高危保护**：页面跳转用 `<a>` / `<Link>`（原生支持 `Cmd/Ctrl+Click` 与中键新标签打开，禁止 `<div onClick>` 跳转）；破坏性删除/覆盖动作必须提供二次确认或可撤销窗口。
- **水合安全（SSR/CSR）**：带 `value` 的输入框必配 `onChange`（非受控则用 `defaultValue`）；涉及本地时区/当前时间的渲染做好客户端挂载保护，避免水合错位，仅在确有必要处局部使用水合抑制。

## 四、网络、全状态码错误恢复与并发防重

### 1. 全状态码与离线恢复矩阵

| 错误类型 | 界面正确响应 | 禁止做法 |
| --- | --- | --- |
| **400（参数校验失败）** | 解析字段级错误精准定位到对应输入框并保留原输入 | 只弹一句“请求参数错误 (400)” |
| **401（未认证/过期）** | 提示会话已过期，引导重新登录并**记住当前路径登录后回跳** | 静默白屏或直接清空草稿踢回首页 |
| **403（无权限）** | 明确说明缺少哪项权限、谁能授予或只读替代视图 | 暴露裸 403 页面或把按钮藏起无任何说明 |
| **404（对象不存在）** | 告知对象已被删除或链接失效，给出返回列表/首页出口 | 页面崩溃抛未捕获异常 |
| **429（触发限流）** | 告知操作频繁与建议重试等待时间（读取 `Retry-After`） | 无限静默重试或报系统故障 |
| **500 / 超时 / 离线** | 诚实说明服务不可达或网络已断开，保留本地草稿并提供**立即重试**按钮；局部模块报错不得拖垮整页 | 整页白屏或显示堆栈/数据库报错 |

### 2. 并发防重、竞态取消与内存防泄漏

- **防连点提交**：提交期间禁用重复触发或做幂等锁（连续狂点 10 次只发出 1 次有效请求）。
- **竞态与清理**：搜索输入防抖（约 `300ms`）、滚动监听节流（约 `100ms`）；新请求发出或组件卸载时用 `AbortController` 取消过期请求，并清理事件监听、定时器与订阅；乐观更新失败必须完整回滚 UI 状态并提示用户。

## 五、自定义手势与中断恢复加固

针对滑块、对比拉杆、拖拽排序、画布平移与可横向滚动控制条，必须防护以下全部中断异常：

1. **多指并发保护**：记录首个 `pointerId`，拖拽中途第二根手指落下时保持原拖拽对象或干净结束，绝不让滑块突然瞬移到第二指位置。
2. **完整中断清理**：同时监听 `pointerup`、`pointercancel`（浏览器接管滚动）、`lostpointercapture` 与窗口 `blur`——任何一种触发都必须**立即清除拖拽态并释放指针捕获**，防止界面卡死在“永远粘着鼠标”的状态。
3. **拖拽期防干扰**：拖拽过程中临时关闭文本选中（`user-select: none`），对被拖拽镜像/遮挡元素设置 `inert`；拖拽结束后立刻恢复。
4. **非手势等价替代**：所有拖拽、滑动、捏合或路径手势（除非属于绘图等本质手势功能），必须同时提供**点击按钮与键盘方向键/快捷键**替代操作。
5. **异常后自愈**：经过上述任一中断后，下一次点击或拖拽必须直接生效，无需刷新页面。

## 六、无障碍与焦点管理硬底线

- **语义 HTML 优先于 ARIA**：动作一律用 `<button type="button|submit">`，导航一律用 `<a href="...">`，**绝对禁止 `<div onClick>` 或 `<span onClick>` 冒充按钮**。
- **完整可读名称**：纯图标按钮必配 `aria-label`；纯装饰图标设 `aria-hidden="true"`；信息图写清 `alt`，纯装饰图设 `alt=""`；有声/动态教学媒体配字幕或文字稿，媒体控件可键盘操作。
- **地标与标题阶梯**：严格按 `<h1>`–`<h6>` 顺序嵌套不跳级；提供跳转主内容的 Skip Link；锚点标题设置 `scroll-margin-top` 避免被粘性顶栏遮挡。
- **异步播报**：Toast、保存结果、表单总错与筛选数量变更使用 `aria-live="polite"`（紧急阻断错误可用 `assertive`）。
- **焦点管理**：
  - 严禁裸写 `outline: none` / `outline-none` 而不提供高对比 `:focus-visible` 替代环；
  - 优先 `:focus-visible`（避免鼠标点击乱亮边框），复合输入组用 `:focus-within` 高亮整体；
  - 粘性顶栏、底栏与浮层绝不能遮挡当前获得焦点的元素；
  - 模态对话框打开时捕获焦点（Focus Trap），按 `Esc` 关闭并将焦点精确归还至触发按钮；
  - 严禁 `<meta name="viewport">` 中写 `user-scalable=no` 或 `maximum-scale=1` 禁用用户缩放；
  - 谨慎使用 `autoFocus`——仅限桌面端单一主搜索/输入页，移动端默认禁用（防止刚进页就顶起虚拟键盘遮住半屏）；
  - 在 Windows 高对比度（Forced Colors）模式与纯键盘 `Tab` 全路径下验证可见可用。
