## AI Coding

- Agent 开始任务先读取 `PROJECT_CONTEXT.md` 和相关 canonical docs。
- Agent 完成任务前执行 documentation impact analysis。
- 不把一次性聊天偏好升级为项目规则。
- 不把个人跨项目偏好提交到共享仓库。

## Decisions and exceptions

- 重大例外必须记录原因、Owner 和退出条件。

## Change policy

新增或修改约定时，应能回答：

- 适用于哪些任务？
- 为什么需要自然语言规则而不是 CI？
- 是否与现有规范重复？
- 谁负责维护？
