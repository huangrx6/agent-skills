# 文档 → 思维导图预处理器

仅当必须首先读取/提取源材料时才使用此分支。

## 接收

在总结之前先阅读实际来源。根据主机的不同，来源可能是本地文件、附件、网页、图像、会议记录、报告、论文、书籍章节、Markdown 或粘贴的长文本。

不要捏造缺失的源内容。

## 提取流程

1. 识别文档的目的和用户的期望结果。
2. 在可用时捕获标题/摘要/目录/章节标题。
3. 将有意义的标题层次结构保留为初始骨架。
4. 将长叶段落浓缩为一个或几个简洁、忠实的要点。
5. 提取高价值的结论、概念、事实、步骤、决策、证据、风险、建议、责任人和行动（视情况而定）。
6. 合并重复项并规范化并行分支。
7. 保持结果忠实于来源；如果需要推断，请区分推断和源内容。
8. 生成适合思维导图引擎的干净 Markdown 层次结构。

然后按照 `references/mindmap.md` 的说明操作，但使用以下命令调用客户端：

```bash
printf '%s' "$MARKDOWN" | node scripts/processon-mindmap.mjs \
  --mode document \
  --title "<title>" \
  --structure mind_free \
  --markdown -
```

`document` 模式在使用与通用思维导图引擎相同的转换端点时，保持独特的 ProcessOn 来源/合作伙伴身份。
