# Obsidian 工作台

在本地笔记中维护清楚的需求、缺陷、任务与工作事实，项目页和周报负责汇总导航。
本 skill 可独立安装和运行，不加载其他 skill，不自动生成学习笔记。
记录、整理和分工不授权执行发布、SQL、git 或发送通知；用户要求接入视图时，可配置所需核心插件和首页样式。

## 找到工作区

命令相对于本 skill 目录：

```sh
python3 scripts/vault_path.py --explain
```

路径依次取显式参数、`OBSIDIAN_VAULT_PATH`、`$AGENT_SKILLS_CONFIG_DIR/obsidian-vault-path`
（默认配置目录 `~/.config/agent-skills`），兼容旧文件 `~/.config/obsidian-vault-path`。
未配置或目录不存在时可先整理草稿，说明缺口，不猜其他知识库。

先看目标项目目录的直接子项、项目主页和近期记录，沿用现有命名、属性与模板。工作项可以在任意
用户指定工作目录，不要求 PARA、特定插件或目录重组。明确指定的新路径检查冲突后可直接创建；
落点不明时优先已有主家，临时捕获按实际收件箱约定处理，无法判断的新结构再澄清。

## 按任务处理

| 请求 | 读取与执行 |
| --- | --- |
| 需求、缺陷、任务、负责人或项目状态 | [工作项与日常管理](references/work-items.md)：识别已有工作项，更新主档和必要项目导航 |
| 每日记录、测试、发布、回滚或纠错 | [事件记录](references/event-records.md)：分开状态和证据，按事件去重 |
| 周计划、周报或工作台汇总 | 工作项规则：按时间范围和实际记录汇总，链接原条目，不另建事实副本 |
| 外部系统导出、截图、粘贴材料或同步要求 | [外部协同](references/external-collaboration.md)：区分本地主档与外部快照 |
| 接入 Bases、设计工作台首页或调整视图 | [Bases 视图](references/bases-views.md)：使用包内首页、视图、模板和局部样式，实际打开验证 |
| 已有八章周发版格式 | [兼容模板](references/release-note-template.md)：保留现行格式，按需使用旧检查器 |

1. 先辨别本次要求是新增、更新、汇总还是审阅；“帮我看看”只给发现，不直接修改。利用上下文确认
   项目和对象，不因“记一下”反复追问；材料缺少必要对象时再澄清，同时整理已知事实。
2. 查已有 ID、标题、父需求和关联项。独立工作项复用持久 `work_id`；重复输入不重复建项。
   简单一次性待办保留在现有清单，需独立负责人、状态或验收的事项再单页管理。
3. 分别写清需求的目标与验收、缺陷的复现与实际表现、任务的动作与交付。负责人仅按已知分工或
   用户本次指定填写，未知写“未提供/待确认”；明确尚无人负责才写“未分配”。建议分工标为建议，不擅自分派或通知。
4. 更新事实与下一步，计划不得写成结果。实现、验证、发布、回滚有各自的状态和依据；事件时间与
   记录时间分开，来源不足标明用户陈述或待确认。纠错保留必要历史，不保留两份相互冲突的当前状态。
5. 项目主页、日常记录和周报链接工作项主档；日常记录可记发生过的变化，汇总中的状态标明截至时间。
   与学习笔记的关系只用用户指定或已存在的普通链接，不要求读取或调用其他 skill。

保留原有属性和有效内容，只在内容实际改变时更新修改日期。移动、改名或合并前搜索全库旧名称和
路径的入链，修订受影响双链、Markdown 链接与索引；不假定应用会替文件操作自动修链。
未要求清理时保留附件、隐藏目录和插件配置；敏感值只写变量名和位置。

## 验证与交付

人工核对工作项身份、关系、状态依据和汇总范围；链接、文件名或位置改变时运行：

```sh
python3 scripts/check_links.py --vault "<知识库路径>" --ignore-template
```

它只检查双链和嵌入的目标文件，不检查 Markdown 链接、标题或块锚点、关系语义、ID 唯一性或事实真伪。
原有断链单独报告，不能为返回成功而删掉待写链接或补造内容。

仅对兼容八章周发版格式运行：

```sh
python3 scripts/check_release_note.py "<笔记路径>" --vault "<知识库路径>"
```

该命令保留原文件名、ISO 周/日期、H1、模板全部字段与章节、同目录重复周和双链入链检查；
明显凭据赋值只作提示。它不识别工作项或事件重复，不验证状态含义、来源真实性、命令或发布安全性。
未配置知识库时跳过入链检查并说明；轻量记录、自定义格式、需求/缺陷/任务均不适用这个格式检查器。

返回实际新增或更新的位置、状态和负责人变化、汇总范围、已做检查及信息缺口。
没有新信息时说明未重复写入；本地记录不代表远端同步成功。不自动提交 git、改 skill 或重建整库。
