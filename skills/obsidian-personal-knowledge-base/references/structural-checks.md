# 结构检查

脚本路径相对于本 skill 目录。所有命令只读；脚本默认按 `vault_path.py` 解析 vault，
也可用 `--vault PATH` 指定测试目录或本次目标。

## 链接检查

```sh
python3 scripts/check_links.py --ignore-template
python3 scripts/check_links.py --vault /path/to/vault --json
```

检查 Markdown 笔记里的 wikilink 与嵌入，包括笔记和附件；忽略围栏代码与行内代码，
跳过隐藏目录、缓存、插件和嵌套主题仓库。`--ignore-template` 跳过路径中 `Templates/` 的笔记。
解析文件路径、相对路径和短名称，移除别名与锚点后检查目标文件。

退出码：`0` 未发现失效目标、`1` 发现失效目标、`2` vault 解析失败或不存在。
`--quiet` 只输出失效引用数量，`--json` 输出文件、行号、目标和 link/embed 类型。

**范围限制**：不验证标题/块锚点、不检查 Markdown 链接、HTML 链接或远程 URL，
不判定同名短链接是否指向语义上正确的笔记。复杂 Markdown 嵌套也可能需要人工查看。
因此返回 `0` 不能代替移动/拆分后的入链审阅。

报告已有失效链接时保留原意：目标已改名则修正；拆分则选对应子笔记；
有意预留的笔记链接可保持并说明。无法推断目标时报告缺口，不能自动删成纯文本或编造新笔记。
只读审阅不直接改链接；修订任务仅处理授权范围内的问题。

## 配置路径检查

```sh
python3 scripts/check_paths.py
python3 scripts/check_paths.py --vault /path/to/vault --json
```

扫描 `.obsidian/` 下的 JSON、JSON5、YAML、TOML 配置，提取常见 POSIX 绝对路径及 `~/`。
不扫描正文中的示例路径或插件打包 JS。存在性检查按本机文件系统进行；`~/` 展开后存在不代表插件也会展开。

以扩展名启发式分类：缺失的疑似文件计失败，无扩展名或显式尾斜杠路径计提示。
退出码：`0` 无失败（可能有目录提示）、`1` 有疑似文件缺失、`2` vault 不可用。
`--quiet` 只输出失败数量；需要目录提示时使用默认或 JSON 输出。

**范围限制**：不是配置格式解析器，也不了解各插件语义；不覆盖 Windows 路径、所有 POSIX 根目录、
JSON 转义形式或相对路径。无扩展名的可执行文件、带点目录和待创建输出文件均可能分类不准。
没有 `.obsidian/` 或没有可识别路径也会返回 `0`。

修复前确认插件对该字段的路径规则：可能要求绝对路径，也可能支持 vault 相对路径、`~` 或 PATH。
不能统一替换成某一种形式。仅修改本任务涉及的配置，不把启发式提示当成自动删除或提交阻断策略。
