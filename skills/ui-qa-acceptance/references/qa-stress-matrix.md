# 7 维度高压交互验收矩阵

需求文档中的 AC 只描述「正常路径应该发生什么」，而生产事故几乎都藏在状态残留、极端数据、窄/矮视口、键盘焦点断裂、并发连击与手势中断里。凡涉及页面、弹窗、列表、表单、设置或导航改动，无论 AC 是否显式提及，均须按本矩阵逐维高压复测。

---

## 维度 1：核心主路径与持久化闭环

### 测试载荷
- 一组真实业务数据：新建项、修改字段、切换开关/状态、触发删除（含破坏性操作确认/撤销）。
- URL 状态参数（若页面含筛选器、标签页、分页或展开面板）。

### 操作步骤
1. 从真实用户可见入口（导航栏、主按钮、菜单）出发，按完整顺序走完「创建 → 编辑 → 切换状态 → 删除」。
2. 观察每一步的即时反馈：按钮进入明确加载态（如 `Saving…`）、列表计数与内容同步更新、异步提示条可见。
3. **强制持久化复核**：执行硬刷新（`page.reload()`）或完全关闭后重开应用，重新进入同一页面核对所有改动。
4. 测试有状态 UI 的 URL 同步：切换筛选/Tab 后复制当前 URL 在新标签页打开，确认视图状态还原；测试链接支持 `Cmd/Ctrl+Click` 或中键新标签打开（真实 `<a>` 而非 `<div onClick>`）。
5. 在含未保存编辑的表单中直接尝试切页或关闭窗口，核对是否有离开确认提示（`beforeunload` 或路由守卫）。

### 明确通过 / 失败判据
- **通过**：操作即时反馈清晰，刷新或重开后状态与操作后完全一致；破坏性删除均有二次确认或撤销窗口；有状态链接可深链还原且支持常规新标签打开。
- **失败**：页面看似变更但刷新后回滚（仅改内存未落盘）；破坏性操作一点即不可逆删除；使用 `<div>` 绑定点击导致无法新标签打开或复制链接；未保存编辑直接丢失且零提醒。

## 维度 2：切页、关闭与重开状态复位

这是 SPA 与桌面工具最高发的隐蔽缺陷区，必须逐条演练全部退出路径。

### 测试载荷
- 制造“脏局部状态”组合：搜索词 `not-exist-qa-999`（触发无结果空态）+ 切到二级 Tab/详情子视图 + 展开 2 个折叠面板 + 列表向下滚动至中后段（`scrollTop > 200`）。

### 操作步骤
1. 打开目标弹窗 / 抽屉 / 设置子页，注入上述全部脏状态。
2. 依次用以下 **4 种退出方式** 关闭或离开，然后立即重新打开：
   - 点击右上角关闭按钮或「取消」；
   - 按下键盘 `Esc`；
   - 点击弹窗外部遮罩区域；
   - 不手动关闭，直接点击侧边栏切到另一主页面再切回。
3. 弹窗打开期间，在弹窗内容滚到底后继续向下滚动滚轮，观察背后主页面是否跟着滚动（滚动穿透）。

### 明确通过 / 失败判据
- **通过**：4 种路径重新进入后，搜索框为空（不残留 `not-exist-qa-999` 和过期的「无匹配结果」空态）、回到默认首层视图、列表滚动位与选中态符合约定；弹窗内部滚动不带动背后主页面（`overscroll-behavior: contain` 生效）。
- **失败**：任意一种退出路径重开后仍卡在旧搜索词、旧空态或已离开的详情子页；关闭后底层数据被误改；弹窗滚到底触发背景页滚动穿透。

## 维度 3：极端数据量、空态与粘性滚动容器

### 测试载荷
- **0 条**（完全无数据初始态）
- **搜索无匹配**（底层有数据，输入不存在关键词）
- **1 条**（单条边界，核对单复数、分割线、删除最后一条后过渡到空态）
- **30 条 & 100+ 条**（中高数量；涉及长列表或大数据表时加测 **1000+ 条** 验证虚拟滚动或分页）

### 操作步骤
1. 清空数据至 0 条，检查页面骨架、空态引导文案与主操作入口。
2. 在有数据状态下搜索无结果，检查空匹配提示与「清空搜索」按钮；点击清空后核对已有勾选状态是否保留。
3. 注入 30 条与 100+ 条记录：
   - 向下滚动至列表中部与最底部；
   - 检查搜索栏/表头是否保持吸顶可见；
   - 检查列表主体是否独立滚动而非撑爆整个视口；
   - 滚到底部后检查最后一项的文字、右侧操作按钮与底部边距是否完整露出；
   - 核对底部主操作栏（如「确定 / 保存」）是否始终固定可见。
4. 若列表 > 50 条，抽查滚动帧率与 DOM 节点数，确认大数据集已做分页、虚拟滚动或 `content-visibility: auto`。

### 明确通过 / 失败判据
- **通过**：0 条与搜索无结果均给出明确说明与下一步行动；30/100+ 条时搜索区与底部操作栏稳定固定，列表滚到最底最后一项 100% 可见可点（不被粘性底栏压住哪怕 1px）；大列表无明显卡顿。
- **失败**：空态呈现破损空表格或永久加载圈；长列表把底部确认按钮顶出视口无法点击；滚到最底时最后一项被粘性底栏遮挡；一次性挂载上千个重 DOM 节点导致页面假死。

## 维度 4：超长文案、国际化/RTL 与多视口缩放

### 测试载荷（直接复制注入标题、名称、路径、描述字段）
- **超长中英混排（70+ 字符）**：`超级扩展插件配置项_EnterpriseWorkspaceIntegrationModule_用于验证极端宽度下省略与折行边界_2026`
- **无空格超长 URL / 路径**：`https://internal-registry.example.com/v2/organizations/platform-engineering/packages/ultra-long-unbreakable-identifier-segment-0123456789abcdef`
- **多字节 Emoji 与特殊符号**：`🚀 自动化验收测试 🧪✨👨‍👩‍👧‍👦 <script>alert(1)</script> "引号" & 符号`
- **大数字与多语言**：`1,234,567,890.99`、`999999+`；德语长词扩展（比英文长 30%–40% 如 `Einstellungsübersicht`）；若页面支持 RTL（`dir="rtl"`），注入阿拉伯语/波斯语（含 ZWNJ `U+200C` 如 `می‌خواهم` 与波斯/阿拉伯字母变体）。

### 视口与缩放矩阵
- **常规桌面**：`1440×900`、`1280×800`
- **紧凑窄窗**：`900×620`（桌面侧栏收窄）、`390×844`（移动端竖屏）
- **矮窗**：`1280×560`（检验弹窗/下拉菜单高度自适应与内部滚动）
- **字体/页面放大**：浏览器缩放 `200%`（WCAG 文本缩放要求）

### 操作步骤
1. 将上述极限文案分别写入列表标题、卡片描述、面包屑、下拉选项与弹窗标题。
2. 依次切换上述 4 组视口与 200% 缩放，在每个视口运行横向溢出与元素裁切检测脚本。
3. 检查弹窗、下拉菜单、Tooltip 在矮窗（`1280×560`）与窄窗下是否自动限高并出现内部滚动条。
4. 检查移动视口（`390×844`）下的表单输入框字号（须 ≥ 16px，防 iOS Safari 聚焦强行放大）、交互热区尺寸（推荐 ≥ `44×44px`，WCAG 2.5.8 AA 底线 `24×24 CSS px` 且不与相邻小目标重叠）及全屏安全区留白。
5. 若页面声明 `dir="rtl"`，验证真实渲染方向、逻辑边距（有无左右边距冲突叠加）及返回/展开箭头是否符合阅读方向。

### 明确通过 / 失败判据
- **通过**：所有视口下 `document.documentElement.scrollWidth <= window.innerWidth`；长文本安全省略（`text-overflow: ellipsis` / `line-clamp`）或断词折行（`overflow-wrap: anywhere/break-word`），Flex/Grid 子项具 `min-w-0`，右侧开关/删除/箭头按钮 100% 留在容器内；按钮文字不发生畸形逐字竖排；200% 缩放下内容可读且不重叠；原始 HTML 标签文本安全转义渲染。
- **失败**：出现非预期横向滚动条；右侧操作按钮被挤出容器或被裁切；矮窗下弹窗顶部标题或底部按钮伸出视口外无法触及；固定宽度按钮把德语/中文文案撑破边框；HTML 字符串被当成代码执行。

## 维度 5：键盘导航、焦点闭环与表单无障碍

### 测试载荷
- 仅使用键盘（不碰鼠标/触控板）：`Tab`、`Shift+Tab`、`Enter`、`Space`、`Esc`、方向键（`ArrowUp`/`ArrowDown`/`ArrowLeft`/`ArrowRight`）、`Home`/`End`。

### 操作步骤
1. 从页面顶部按 `Tab` 逐项遍历所有可交互控件，核对顺序是否与视觉阅读顺序一致，确认首步有跳过主内容链接（Skip Link，若为长导航页面）。
2. 检查每一个聚焦态控件的视觉焦点环，核对是否存在 `outline: none` 且无替代环的情况，核对当前聚焦控件是否被粘性顶栏/底栏盖住。
3. 用 `Enter` / `Space` 激活按钮、复选框、开关与链接，确认不是无法聚焦的 `<div onClick>`。
4. 用键盘打开弹窗/下拉菜单 → 在弹层内按 `Tab` 绕行确认焦点约束在弹层内且无死锁 → 按 `Esc` 关闭 → 核对 `document.activeElement` 是否精准归还给原触发按钮。
5. 列表/标签页/菜单组件用方向键切换，核对高亮滚动跟随。
6. 表单专项检查：点击 `<label>` 是否聚焦对应输入框；尝试粘贴（`Cmd/Ctrl+V`）密码/邮箱/验证码确认未被 `onPaste` 拦截；触发表单校验错误后核对错误提示是否内联显示在字段旁、是否自动聚焦到首个错误字段；检查图标按钮有无 `aria-label`、Toast/异步报错有无 `aria-live="polite"`。

### 明确通过 / 失败判据
- **通过**：全部核心路径可纯键盘闭环完成；每个可聚焦控件都有清晰 `:focus-visible` 且不被粘性栏遮挡；`Esc` 关闭后焦点准确回到触发源；表单标签可点击、不阻断粘贴、错误内联且自动定位首错。
- **失败**：核心按钮无法被 `Tab` 到达；焦点完全不可见或被粘性底栏遮住；按 `Esc` 关不掉弹窗或关掉后焦点掉回 `<body>`；陷入无法退出的键盘焦点死循环；纯图标按钮缺少可访问名称。

## 维度 6：非法输入、并发 5 连击、手势中断与错误恢复

### 测试载荷
- **非法/边界表单输入**：空字符串 `""`、纯空格 `"     "`、超过上限字符、非法邮箱/URL（`http://`、`javascript:alert(1)`）、负数或 `NaN`、已存在重名项。
- **模拟异常网络/接口**：通过 Playwright `page.route()` 注入 `400`、`401`、`403`、`404`、`429`、`500`、延迟 10s 超时与 `context.set_offline(True)` 断网。

### 操作步骤
1. **非法输入校验**：逐项提交非法载荷，检查校验是否给出明确原因与修正建议，且**保留用户已填写内容**（不一键清空让人重写）。
2. **并发 5 连击防重**：在保存、创建、安装、删除按钮上，于 400ms 内快速连续点击 5 次（或配合 `page.route` 给写请求加 800ms 延迟模拟真实慢网），监听网络请求数与最终落盘记录数。
3. **手势中断压测**（适用于自定义滑块、拖拽排序、可拖动分割条、横向滑动控件条）：
   - 按下拖动到一半时，**不松手直接把指针移出控件或窗口外再松开**；
   - 拖动中途模拟窗口失焦（触发 `blur`）或派发 `pointercancel` / `lostpointercapture`；
   - 若支持多点触控合成，拖动中途落入第二指；
   - 中断结束后，再次执行一次正常的点击或拖拽，确认无需刷新页面即可正常工作；
   - 在报告中明确写清手势证据来源（模拟视口 / 合成触摸 / 浏览器引擎 / 真机）以及未测部分。
4. **接口报错与断网恢复**：注入 500/429/超时/断网，确认界面给出明确报错与「重试 / 取消」入口；恢复网络后点击重试，确认流程可顺利恢复。

### 明确通过 / 失败判据
- **通过**：非法输入被友好拦截且保留用户输入；5 连击期间按钮进入禁用或幂等去重，仅发出 1 次有效写请求、仅产生 1 条数据；所有手势中断都能清理拖拽态并释放指针捕获，紧接着的下一次操作直接成功；任何接口报错后加载态必解除且支持原地重试。
- **失败**：提交非法数据导致前端白屏或清空整个表单；5 连击发出多条重复写请求并产生重复数据；手势中断后滑块/拖拽幽灵吸附在鼠标上卡死直到刷新；接口报错后按钮永久转圈无法再操作。

## 维度 7：运行时洁净度、媒体资源与动效稳定

### 测试载荷
- 全程持续运行的 `console` / `pageerror` / `response` / `requestfailed` 监听器。
- `prefers-reduced-motion: reduce` 媒体特性切换（Playwright `page.emulate_media(reduced_motion="reduce")`）。

### 操作步骤
1. 走完维度 1–6 全程后，拉取并审查全部 Console 报错与警告（尤其关注未捕获 `TypeError`/`ReferenceError`、`UnhandledPromiseRejection`、React `Each child in a list should have a unique "key"`、嵌套 `<button>`、Hydration mismatch）。
2. 审查全程 Network 记录：除维度 6 主动注入的故障外，核对所有 `status >= 400` 请求、死链资源与重复请求风暴（同一接口短时间被无意义重发多次）。
3. 运行坏图、字体与布局偏移扫描：核对所有 `<img>` 的 `naturalWidth > 0` 且具备显式宽高/纵横比防止 CLS；核对 `document.fonts` 无加载失败字体；核对页面累积 CLS（目标 `< 0.1`）。
4. 动效压力与降级检验：
   - 对折叠面板、抽屉、弹窗、切换开关执行**连续 5 次快速点击（间隔 80–120ms）**，验证动画可中断、响应最新意图且最终停在正确终态（不卡半开、不留半透明遮罩）；
   - 开启 `reduced_motion="reduce"` 后重新触发关键交互，核对装饰循环动画已停止，且状态切换反馈仍清晰可辨（不是粗暴清空反馈导致看不出变化）；
   - 检查超过 5 秒的自动播放动画或视频是否提供暂停/停止/隐藏控制。

### 明确通过 / 失败判据
- **通过**：全程 0 未捕获 Console Error、0 未处理 Promise 拒绝、0 非预期 4xx/5xx、0 坏图、无明显 CLS 跳动；快速 5 连开合落定状态准确；开启减少动态效果后无刺眼循环且状态反馈完整。
- **失败**：存在未捕获前端异常或资源 404/500；存在裂图或缺失宽高导致首屏加载跳动；快速连点后组件卡死在半展开态或遗留遮罩阻挡点击；自动播放超 5 秒且无法暂停。
