# 拥挤关系图的阅读视图

线没有精确重叠，仍可能因距离太近、跨层过长或反复转折而难以追踪。
目视审查时沿每根线从起点走到箭头，不把几何检查 pass 当作已经易读。
先用节点次序、方向约束、独立引出端口和足够的层间空档改善；同时看线是否穿过分区标题，
不要只增大所有节点间距。不要用每条线一种颜色、删关系或合并不同语义的边掩盖问题。

显式文档/投影/打印预设会尝试一轮有界走线细化：对齐独占支路，重选可直连的端口，
平行线留出间距，侧向汇入时避开区域标题。新候选必须重新通过全部几何检查，
不增加已有问题才接受；环路和折栏沿用原路由。fit 保留既有布局，但实际交叉漏检的修正对所有模式生效。
文字定位在直线段旁搜索，并把区域边框加入避让；Excalidraw 与 draw.io 共用位置计算，
draw.io 用边标签 offset 保持绑定。官方渲染仍可能出现字体/端点差异，需复核。
横向布局会根据注释字号和宽度预留层间空间，包含文字两侧与分区边界的余量；
仍受现有间距上限约束，超长文字或密集关系需要检查提示并调整阅读视图。

当前起点为图内线距 24、文字间隔 10、非端点节点避让 16、平行边框间隔 18。
显式阅读预设的未折栏 TB 图还会在路由前按**分组外框**预留层间净空：
依据字号从至少 80 图内单位起算，跨层横向走线密集时增加有上限的通道余量。
它移动完整层及其辅助节点，保留同组内部间距，含回边也会生效；不以缩框代替留白。
标题顶边留白随字号计算，标题带高度与真实行数一致。放不下的长标题可保留全文换行。
这些是生成器的保守搜索值，不能当作缩小观看后的像素保证或任意图的全局最优解。
Excalidraw 可额外输出几何回执：

```sh
python3 scripts/readable_routing.py view.excalidraw -o "$diagram_check_dir/view-readability.json"
```

`$diagram_check_dir` 为本次临时目录；需要留存的报告收进 `.source/checks/`，不散落在成品旁。
该检查发现近距离平行线、真实交叉、上下分区外框过近、边标签/分区标题靠线过近时返回 warning；边标签还要避开区域边框与节点。
显式场景生成时会把未解决项列为可读性提示，不会仅因节点/文字包围盒没有重叠就宣称整体易读。
目前不量化任意曲线、纹理噪声、每个字形轮廓或所有编辑后变化；draw.io 的标签间隔仍以官方渲染目检为准。

若一张图承载多个阅读问题，可交付一组相互对应的视图。按问题拆，不按固定节点数机械拆；
用户要求单图时优先保留单图，具体限制另行说明。需要把不同方向的视图放进同一张画布时，
用 [混合方向](mixed-direction.md) 的面板式组合；`split_views.py` 仍输出独立的视图文件。每张图的标题和问题限定其范围，
重复节点用同一 ID、名称、归属及配色；明确每张只是局部视图，分组标题不表示其中展示了全部成员。
整个图集保留所有原始节点和边，长说明可作为原文附录。

## 生成与覆盖核对

作者先写视图计划，再用 `scripts/split_views.py` 提取。脚本不猜哪些边“重要”，不重写业务事实。
计划使用源 edges 数组的 **0 起始下标**，避免同起终点的不同关系被误合并。

```json
{
  "version": 1,
  "views": [
    {"name": "entry", "title": "接入路径", "question": "请求如何进入？", "edges": [0]},
    {"name": "storage", "title": "数据路径", "question": "数据如何保存？", "edges": [1, 2]}
  ]
}
```

每张视图可增加 `nodes` 包含独立节点；所有边端点自动纳入。允许 `direction`、`style`、
`ranks`（节点 ID → 非负整数）和 `pins`（节点 ID → left/right/top/bottom）调整阅读布局，
不会修改节点标签、detail、kind、emphasis、group 或边内容。未覆盖任何节点/边就失败。
重复节点或跨图复用同一条边允许，同一视图内重复边下标报错。

```sh
python3 scripts/split_views.py reading-views/.source/source.diagram.json reading-views/.source/views.json --colors reading-views/.source/project.colors.json -o reading-views/.source/
python3 scripts/emit_excalidraw.py reading-views/.source/entry.diagram.json --colors reading-views/.source/entry.colors.json --preset doc-wide --quality showcase
```

输出每张 `*.diagram.json`、对应的配色文件（剔除该视图之外的 ID 映射）、`notes.json` 和 `coverage.json`。
覆盖回执记录源规格规范化哈希、每个节点和原始边出现在哪些视图，以及完整原始说明。
保留 source、计划、回执和说明共同交付，制作资料集中在 `.source/`，阅读成品放外层，见 [文件组织](delivery-files.md)。
视图名避开源文件和计划的文件名，防止覆盖输入。脚本先对完整源图验证颜色映射，避免过滤时吞掉拼写错误。

每张仍需原生检查；需要交付图片或刷新已有图片时再真实导出和逐线目检，不为拆图例行生成预览。
覆盖通过只证明源规格没有漏项，不证明源规格本身正确，
也不能把多张局部图的通过状态称为单页总览通过。变更源文件后重新生成覆盖回执。
