# Flowcharts and state diagrams

Flowcharts communicate decisions and procedural order.
- `process` -> rectangle
- `decision` -> diamond
- `start/end` -> ellipse
- keep branch labels short (`yes`, `no`, `retry`, etc.)
- converge branches where the implementation actually reconverges

For state diagrams, nodes are states and edges are events/guards. Do not mix implementation steps and states in the same view.
