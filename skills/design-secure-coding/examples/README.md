# 示例：安全编码评审产出样例（虚构项目）

> 本项目设定：虚构公司 "NovaPay"（与其他 skill 示例同项目），Java 21 + Spring Boot。
> 演示用本 skill 对一段含漏洞代码做 Source→Sink 评审 + 修复 + 安全例外。
> **本示例不抄用、仅作参照——实际项目以自身技术栈和威胁模型为准。**

## 文件

- `security-review.example.md` — 对订单查询接口的完整安全评审（Source/Sink 识别 → 控制 → 修复 → 测试 → 例外）

## 要点

1. **Source 追踪**：从 HTTP 参数追踪到 SQL 拼接 Sink，不只看 Controller 层。
2. **上下文控制**：不用通用 `sanitize()`，用参数化查询 + allowlist 映射排序字段。
3. **授权独立检查**：认证通过 ≠ 有权限，逐资源执行授权。
4. **安全例外**：无法立即修复的控制用例外模板记录 Owner/期限/补偿/退出条件。
5. **AI 生成代码**：同一段代码视为"未审查"，评审标准与人工代码相同。
