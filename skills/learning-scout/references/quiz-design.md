# 自测题设计

自测的目的不是给人打分，是让读者在读完的第二天还能把结论重建出来。
所以判断标准不是「题目像不像考试」，而是「答完这道题，读者有没有真的想一遍」。

每篇 1–3 题，放在正文之后。没有题目也可以，但不要为了凑数量出「什么是 X」这种
翻回去就能抄的题。

## 一、先选题型：回忆强度阶梯

同样一个知识点，三种问法的检验强度差别很大：

| 题型 | 读者要做什么 | 强度 | 适用 |
| --- | --- | --- | --- |
| 短答 `short` | 从空白开始写出解释 | 最高 | 机制、因果、取舍 |
| 选择 `choice` | 从给定选项里认出一个 | 中 | 容易混淆的概念、边界判断 |
| 判断题 | 二分 | 最低 | 几乎不用，除非错得很有意思 |

只用选择题的问题是：四个选项摆在眼前，正确答案会被「认出来」，读者容易把
**眼熟**当成**会**。所以在选择题之外，每个系列至少安排几道短答题——哪怕只是
「用自己的话说清这条链路」。

短答题不给选项，读者先写在输入框里，再点「对照参考答案」。写出来的东西哪怕很粗糙，
也比在四个选项里点中一个更能暴露「其实没想清楚」。

## 二、干扰项要指向具体误解

选择题的价值全在错误选项上。一个错误选项应该对应一种**真实会发生**的想错方式，
而不是随便编一个明显不对的说法。

判断标准：如果读者选了这个错误项，你能说出他脑子里大概是哪一步搞错了，这个干扰项就合格。

`why` 就是写这一步的地方。它和 `options` 一一对应，错选时就地显示：

```json
{
  "q": "入队成功代表消息已经安全了吗？",
  "options": ["是，已经持久化了", "还要看是否落盘", "取决于队列实现"],
  "answer": 1,
  "why": [
    "入队只写进内存，进程重启就没了",
    "",
    "方向对，但只有少数实现走这种路径，题干没给这个前提"
  ],
  "explain": "入队只保证消息进了内存队列；落盘发生在另一个时点。"
}
```

写 `why` 的常见错误是写成「这个选项不对」——那等于没写。要写清**错在哪一步**。

正确选项一般不需要 `why`，留空字符串即可。

## 三、别让答案从形式上就能猜出来

几个会让题目失效的形式线索：

- **正确项明显更长**。写正确选项时想解释得完整，错误项随手几个字，长度差一眼可见。
  构建脚本会对「正确项超过其他选项平均长度 1.5 倍且不短于 20 字」提示。
- **「以上都/都不对」**。这类选项考的是排除技巧，不是理解。脚本同样会提示。
- **绝对化措辞只出现在错误项**。如果错误项全带「一定」「永远」，读者不看内容也能排除。
- **题干照抄小标题**。把 `## 3. 落盘时机` 直接变成「落盘时机是什么」，读者只要记得标题顺序。

## 四、一题只考一个点

题干里塞两个概念（「A 和 B 的关系是什么，为什么」），答错时无法判断是哪个没懂，
读者自己也不知道该回去补哪段。

如果确实想把两个点连起来考，那就拆成两题，或者把第二问放进 `explain` 里当延伸。

## 五、`explain` 写到过程层

反馈分三层：任务层（这题对错）、过程层（思路哪里偏了）、自我层（你真棒/你不行）。

- 只写「错了，答案是 B」＝ 任务层，几乎没用。
- 写「入队只保证进内存」＝ 任务层 + 一点解释。
- 写「你的推理停在了『入队成功』这一步；下一步该问的是：这一刻数据在哪一层」＝ 过程层，最有用。
- 自我层的评价（「这题很简单」「你应该会」）不要写。

`explain` 和 `why` 的分工：`why` 解释**这个选项**，`explain` 解释**这道题考的那个判断**。

## 六、避免「刚翻回去就能抄到」

这是自测题最常见的失效方式：题干和正文某句话几乎同构，读者往上翻两行就能找到原句。

三种改法：

- **换情境**：正文讲的是 A 场景，题目问 B 场景里同样的机制会怎样。
- **换方向**：正文说「为什么这样做」，题目问「如果不这样做会怎样」。
- **考取舍**：正文给了方案，题目问「什么情况下这个方案不成立」。

如果一道题在正文里能找到逐字对应的答案，它检验的是翻页能力，不是理解。

## 七、出题后的快速自检

- [ ] 关掉正文，只看题目，能答出来吗？（不能靠猜形式）
- [ ] 每个错误项都对应一种真实的想错方式吗？
- [ ] 答错时读者知道自己错在哪一步吗？
- [ ] 有没有哪道题，答案是正文里的一整句原话？
- [ ] 题量和篇幅匹配吗？（一篇 1–3 题，不要变成刷题库）

## 依据

- Roediger & Butler (2011)、Karpicke & Roediger (2008)：提取练习对长期保持的作用，
  以及「重读带来的熟悉感」为何容易高估掌握程度。
- Wiliam (2011)：关键问题（hinge question）的每个干扰项都应指向一种具体误解。
- Hattie & Timperley (2007)：反馈的层级划分，过程层反馈优于单纯的对错判断。
