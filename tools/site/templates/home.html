Agent Skills

把重复的工作方法，
写成 Agent 能执行、
也能验证的 skill。

@@SKILL_COUNT@@ 个可独立安装的能力，覆盖内容表达、知识工作与开发流程。每个 skill 都带入口说明、可执行脚本和回归测试。

开始使用 浏览 Skills →
quick start 
git clone https://github.com/huangrx6/agent-skills.git
cd agent-skills
python3 tools/install_skills.py

默认安装到 ~/.agents/skills/

@@SKILL_COUNT@@ skills 3 类场景 Python 3.10+ MIT

Skills

每个 skill 独立安装，也可以组合使用。

@@SKILL_GROUPS@@

怎么运作

入口、执行、验证三件事固定下来，能力才可复用。

01

入口

SKILL.md 说明什么时候触发、按什么步骤执行；不靠临场发挥。

02

执行

scripts/ 把确定性步骤写成可运行代码，产物落到文件。

03

验证

回归测试与结构检查守住行为边界；产物质量单独验收。

安装

本机开发用软链，其他 Agent 用官方 CLI。

本机开发

推荐
git clone https://github.com/huangrx6/agent-skills.git
cd agent-skills
python3 tools/install_skills.py

默认软链到 ~/.agents/skills/，改仓库立即生效。

其他 Agent

CLI
npx skills add https://github.com/huangrx6/agent-skills \
  -a claude-code -a codex -g

由官方安装器维护路径与更新；也可以装到项目的 .agents/skills。
