# README 写作参考

README 给使用者解释怎么运行；SKILL.md 给 Agent 指明怎么工作。避免复制完整规则。
按复杂度选用以下内容，不强制所有 skill 套用同一套章节。

1. **用途与边界**：一两句话说明能产出什么、容易混淆的能力归谁。
2. **依赖与配置**：实际安装要求、配置发现顺序、外部工具缺失时的行为。
3. **快速使用**：典型请求和可运行命令，写清命令的工作目录。
4. **输入与输出**：复杂格式给最小示例，详细说明链接到参考文件。
5. **验证与限制**：维护者的验证命令、检查覆盖范围、已知不支持项。

命令路径以实际 CLI 为准，使用占位符替代账号、令牌和机器路径。
README 可以引用仓库专用回归目录；这些引用不放进分发给 Agent 的正文或参考流程。
不要把测试数量、当前未提交文件数、已安装软件状态写成永久事实。
不要求图标或装饰素材；若用户需要或产物确实使用，可以增加并说明用途。
